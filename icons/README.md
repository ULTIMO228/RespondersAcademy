# ARM-112 interface icons

These SVG icons were manually reconstructed from the supplied raster UI references. Raster backgrounds, cell borders, adjacent UI fragments, and scaling/color-fringing artifacts were intentionally excluded. Each SVG preserves the source canvas dimensions and keeps a transparent background so it can act as a drop-in replacement for the corresponding PNG.

## Manual review

The following icons have confidence below 0.85 and should receive manual visual review against the original ARM-112 screenshot: `top-settings`, `top-exit`, `row-important`, `service-status`.

## Usage

```html
<img src="/icons/search.svg" alt="">
```

Use the matching filename for the other icons.
