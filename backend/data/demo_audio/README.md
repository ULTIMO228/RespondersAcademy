- **c-049 — сработала пожарная сигнализация (elevenlabs.io):** `c-049-elevenlabs.mp3`;

коммерческая лицензия бесплатным планом не предоставляется. Перед коммерческой
публикацией или применением перегенерируйте записи на подходящем тарифе.

Все имена и события в репликах — синтетические учебные данные.
