Для отдельного прогона изменён `run_frontend_e2e.ps1`: можно передать `-DatabasePath` и `-LogDirPath` внутри `backend/var/`, чтобы сохранить прежнюю `e2e.db` и её логи; `BACKEND_URL` задаётся до сборки Next.js; процессы тестовых серверов останавливаются после прогона. Git Bash находится также по стандартному пути установки Windows. Администраторский скрипт приведён к текущему API: локальная 2FA не поддерживается, а перед остановкой критичного сервиса завершаются все оставшиеся занятия преподавателя. Временные артефакты находятся в игнорируемом `backend/var/offline-t112*`.
