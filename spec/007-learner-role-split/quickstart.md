## Ручные сценарии (демо-учётки; пароли в `mocks/users.json`)

1. `ivanov` (обе): в кабинете виден переключатель зон; открывает 112 и ДДС; цепочка проходит.
2. `alekseeva` (только 112): `/arm/operator112` открывается; `/arm/card/<id>` и `/arm/phone` → «нет доступа».
3. `kuzmin` (только ДДС): `/arm`, карточка открываются; `/arm/operator112` → «нет доступа»; в карточке адрес, телефоны, ЧС/ЧП, описание — только чтение, статус службы меняется.
4. Преподаватель: мастер назначений для режима 112 не предлагает `kuzmin`; для цепочки — только `ivanov`; результаты и успеваемость разделены по режиму.
5. Специалист 112: «Принять» → заполнение → «Сохранить» + подтверждение → «Зарегистрирована» → «Отработана» → «Закрыть карточку».
6. Администратор меняет специализацию студента → запись в аудите, меню студента обновляется после перелогина.
