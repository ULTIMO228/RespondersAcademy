# 04-pages/00. Вход (`/login`)

**Роли:** все три. **Основание:** ТЗ §5 (многоуровневая аутентификация), §8 (аутентификация при каждом входе), Q&A в14.

**Референс:** `Источники/скриншоты_из_docx/ДДС_image1.png` — экран входа ПОВ-112: голубой иллюстрированный фон (город, вертолёт), «112 ВХОД В СИСТЕМУ», поля «логин»/«пароль», кнопка «ВОЙТИ», под кнопкой — контакты СТП.

## Состав

- Бренд-блок: название тренажёра («Учебный тренажёр оператора ДДС — эмулятор АРМ-112»), пометка «Учебная система. Не является рабочей системой-112» (граница ТЗ §4 — обязательная к показу).
- Форма: «Логин», «Пароль», «Номер АРМ» (как в реальном АРМ-112: логин + пароль + номер АРМ, источник п. 1.1, 3.1), кнопка «Войти» (отправка также по Enter).
- Шаг 2FA (заглушка): поле «Код из сообщения», принимает любой 6-значный код. По умолчанию включён — демонстрация многоуровневой аутентификации ТЗ §5 на экспертизе; отключается настройкой.
- Под формой: блок «Техническая поддержка учебного комплекса» (текст-заглушка, аналог СТП из реального интерфейса).
- Тестовые подсказки на демо: список тестовых учёток из `mocks/users.json` (только в демо-режиме, скрывается флагом).

## Поведение

- Успех → редирект по роли: student → `/arm`, teacher → `/teacher`, admin → `/admin/users`.
- Ошибка: «Неверный логин или пароль» (без уточнения, что именно неверно).
- Заблокированная учётная запись (`User.isActive = false`) → «Учётная запись заблокирована. Обратитесь к администратору».
- Попытка открыть любой защищённый роут без сессии → `/login`; после входа — возврат на запрошенный URL.
- Автовыход через 24 часа непрерывной сессии, если вкладка не закрывалась (как в реальном АРМ-112, источник п. 1.1): сессия сбрасывается, редирект на `/login` с сообщением «Сессия истекла».

## Данные

- `POST /api/mock/auth/login` (логин, пароль, номер АРМ) → `AuthSession`. Моки: `mocks/users.json` (номер АРМ сверяется с `User.armNumber`).

## Критерии приёмки

- Три тестовые роли входят и попадают каждая в свой раздел; чужие разделы недоступны (403).
- Форма содержит поле «Номер АРМ»; шаг 2FA включён по умолчанию и проходит любым 6-значным кодом.
- Автовыход через 24 часа: при эмуляции истечения сессии пользователь возвращается на `/login`.
- Компоновка, поля и типографика — 1:1 по ДДС_image1.png; тренажёрные добавления (бренд-блок, подсказки учёток) незаметны, в той же палитре (`07-design-guidelines.md`).
