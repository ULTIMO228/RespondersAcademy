1. Войти `ivanov` без «Номера АРМ» — ожидание: попадание на `/student`; для `morozova` — `/teacher`, для `admin` — `/admin`.
2. В консоли браузера `document.cookie` — ожидание: `arm112_session` **отсутствует** (cookie `HttpOnly`). В DevTools → Application → Cookies у `arm112_session` отмечен `HttpOnly`.

5. `/account/security`: сменить пароль (слабый и неверный текущий — понятные ошибки); открыть вторую сессию в другом браузере, сменить пароль в первой — во второй следующий запрос даёт 401; «Выйти на всех устройствах» завершает и текущую.

## Диагностика

| Симптом | Причина / действие |
|---|---|
| `/api/v1/*` даёт 404 в dev | Не пересобран фронт после смены `BACKEND_URL` или `.env.local` перекрывает переменную |
| «Раздел требует подключения к серверу» при запущенном бэкенде | Фронт собран без `BACKEND_URL` |
| Лента сообщений служб пуста | Занятие не включало `workMessagesEnabled` или карточка не принята (сообщения планируются при `accepted`) |
| `report-audio` → 503 | Не установлены Vosk и модель `vosk-model-small-ru-0.22` (`backend[stt]`) |
| Запись доклада недоступна в браузере | Не защищённый контекст: нужен HTTPS или `localhost` |
| `start` этапа B → 409 | Вход ДДС ещё не подтверждён преподавателем либо карточка изменилась после подтверждения |
| Вход проходит, но страницы отвечают «Требуется вход» | Cookie `arm112_session` не доходит до бэкенда: проверить `BACKEND_URL` и пересборку, `SameSite=Lax`, `Secure` при HTTPS |
| Повторные e2e-прогоны падают | Не свежий сервер: мок-стор Next живёт в памяти процесса |
