# Фича 002: Сквозная интеграция фронтенда, бэкенда и ИИ-контура

**Две части.** A — интеграция (выводит во фронт готовое бэкенда, чинит основу). B — платформа-«обложка» и безопасная авторизация: фронт перестаёт быть копией АРМ и становится обучающей системой (кабинеты трёх ролей, новый визуальный язык), а симулятор `/arm/*` остаётся точной копией боевой системы (`07-platform-shell.md`).

Замыкает учебный контур «настройка → отработка → отчёт» в обоих режимах обучающегося: выводит во фронт готовые возможности бэкенда волны B (режим специалиста-112, задания и экзамен, лобби, рекомендации, база знаний, сообщения служб, голосовой доклад, цепочка A → B), подключает `/api/v1` в сети и устраняет два дефекта бэкенда (выпавшие роутеры, неполная миграция).

**Статус**: волны W1, W2 и W3 завершены и подтверждены тестами (гейты — `docs/FINAL-GATE.md`); W4 («Приёмка сдачи») выполнена в объёме автоматизируемых задач (демо-стенд одной командой T060 `scripts/demo-up.sh` с холодным стартом за 10-11 с, сценарий скринкаста T061, документация T029 и трассировка требований T030 в `01-requirements-map.md`); задача T061 остаётся открытой до физической записи скринкаста `demo.mp4` владельцем.

## Что важно знать перед планом

1. **Базовая линия бэкенда**: 6 failed / 353 passed / 2 skipped; цель — 359 passed, 2 skipped, 0 failed.
2. **Миграции**: не хватает 13 таблиц из 44; `test_alembic` требует единственную ревизию `0001_initial` — выбор способа исправления (T002) нужно зафиксировать в плане.
3. **Вход в режим 112 только через задание**; попытка восстанавливается через `POST /assignments/{id}/start`.
4. **Цепочка A → B не автоматическая**: между этапами — подтверждение преподавателем.
5. **Сообщения служб** — только если занятие включило `workMessagesEnabled`; текста в контракте нет.
6. **Автономный режим** покрывает только ИИ-панели преподавателя (допущение A3); платформа демонстрируется с бэкендом (A16).
7. **Авторизация сейчас небезопасна**: cookie пишет клиент, `proxy` верит неподписанному JSON — переделывается на серверную `HttpOnly`-cookie (T032–T036).
8. **Есть конфликт с решением владельца 2026-09-18** (копия 1:1): снимается границей «внутри `/arm/*` — 1:1, вне — платформа»; нужно подтверждение (A11).
