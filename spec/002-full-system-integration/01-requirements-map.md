# Карта требований и трассировка: Сквозная интеграция (Фича 002)

Образец — `spec/000-фронт/01-requirements-map.md`. Документ связывает источники требований → истории → FR → критерии успеха → задачи → фактический результат проверки.

**Статус на 2026-09-29**: волны W1–W3 выполнены, W4 подготовлена (стенд T060 и приёмочная документация T029/T030 завершены; T061 ожидает физической записи скринкаста владельцем).

## 1. Источники требований
