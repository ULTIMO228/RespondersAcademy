# Contracts: 008 — профиль режима обучаемого

Изменяются только существующие эндпоинты; новых нет. Типы фронта — `src/shared/api/types/user.ts`; после правки перегенерировать `backend/tests/contract/expected_fields.json` (`backend/scripts/extract_ts_fields.py`).

## Тип

```ts
// src/shared/api/types/user.ts
export type TrainingProfile = "operator112" | "dds";

export interface User {
  // …существующие поля…
  /** [расширение 008] профиль режима обучаемого; нет поля — «не задан», доступны оба режима. Только role = student. */
  trainingProfile?: TrainingProfile;
}
```

## Пользователи (админ)

`GET /admin/users`, `GET /admin/users/{id}`, `GET /api/v1/me` (и мок-слой `app/api/mock/admin/users*`) — `trainingProfile` в ответе, если задан.

`POST /admin/users`, `PATCH /admin/users/{id}` — тело принимает `trainingProfile: "operator112" | "dds" | null`.

| Случай | Ответ |
|---|---|
| значение вне набора | 400 «Профиль режима: специалист системы-112, диспетчер ДДС или не задан» |
| роль не student | поле игнорируется и обнуляется (как `group`) |
| изменение | в аудите в строке изменений: `профиль «Не задан» → «Специалист системы-112»` |

## Задания `/api/v1/assignments`

| Запрос | Новое поведение |
|---|---|
| `POST /assignments` | `400 validation_failed`, если среди `studentIds` есть курсант, чей профиль не допускает `trainingMode`: «Задание режима ДДС нельзя назначить: профиль специалиста-112 — Иванов С. П.» |
| `GET /assignments` (viewer — student) | задания несовместимого режима не возвращаются |
| `GET /assignments` (teacher/admin) | без изменений |
| `GET /assignments/{id}` (student) | `403 forbidden` «Задание режима ДДС недоступно для учётной записи специалиста-112» |
| `POST /assignments/{id}/start` (student, либо teacher с `studentId` такого курсанта) | `403 forbidden`, тот же текст |

## Занятия (`session_engine`)

| Запрос | Новое поведение |
|---|---|
| создание занятия | `400`, если курсант несовместим с `trainingMode` занятия |
| список занятий курсанта | несовместимые не возвращаются |
| вход/карточка курсанта в занятии | `403`, тот же текст |

## Кабинет и рекомендации

| Запрос | Новое поведение |
|---|---|
| `GET /api/v1/recommendations` (курсант с профилем) | без карточек/категорий из истории запрещённого режима и без R10 «Повторить режим …» к нему |
| история и аналитика курсанта (`lobby`: `/me/history`, `/me/analytics`) | только строки разрешённого режима; `byMode` запрещённого режима не показывается фронтом |

## Мастер назначения (UI-контракт)

- Шаг «Обучающиеся»: у курсанта с профилем — метка `112` или `ДДС` рядом с ФИО.
- Шаг «Режим и формат»: при выборе режима, несовместимого с частью выбранных, — `Alert` «Пропущены (профиль специалиста-112): Иванов С. П.»; на шаге «Проверка» таких нет в составе; в `POST` они не уходят.
- Все выбранные несовместимы — ошибка шага «Нет обучающихся для режима ДДС: у выбранных профиль специалиста-112».
