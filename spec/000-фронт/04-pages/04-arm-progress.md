# 04-pages/04. Обучающийся: мой прогресс и справка (`/arm/progress`, `/arm/help`)

**Роль:** Обучающийся. **Основание:** ТЗ §8 (просмотр своих результатов, статистика, рекомендации ИИ, история ошибок; доступ к методическим материалам).

## `/arm/progress` — Мой прогресс

### Состав

- **Сводка**: интегральный балл за период, средняя реакция (против 30 сек), средняя отработка (против 3 мин), количество отработанных карточек, доля без ошибок.
- **История попыток** (таблица): дата, карточка (№, тип), реакция, время отработки, балл, кол-во грамматических ошибок → раскрытие: разбор `Evaluation` (баллы по критериям, ошибки, комментарий ИИ, правка преподавателя если есть).
- **Мои ошибки**: агрегация `Evaluation.mistakes` и `grammarErrors` по всем попыткам, группировка по типам (тайминг / заполнение / грамматика / последовательность статусов / пропущенный звонок).
- **Рекомендации системы** (мок, бейдж «ИИ»): «что улучшить» по анализу ошибок (`aiComment`-подобные тексты из `reports.json`).
- **Сертификат**: мок-кнопка «Скачать сертификат (PDF)» — генерация файла-заглушки на клиенте из мока (ТЗ §12 «PDF для сертификатов»; пометка «этап 2 / опционально»).
- Графики: динамика балла по занятиям, распределение ошибок (простые бар/лайн-чарты; данные `ChartData`).

### Доступ

Только свои данные (`studentId` из сессии); чужие — запрещены (ТЗ §8). Удаление результатов невозможно.

## `/arm/help` — Справочная база

- Список методических материалов (заглушки PDF/DOCX — ТЗ §12): «Памятка работы на АРМ-112», «Инструкция по заведению карточки», выдержки из классификатора.
- Методический материал «Горячие клавиши АРМ-112» — встроенная страница справки (не файл), полная таблица ниже (п. 3.17 единого документа).
- Просмотр встроенным вьювером-заглушкой; поиск по названию.
- Только чтение (обучающийся не может менять материалы — ТЗ §8).

### Методический материал «Горячие клавиши АРМ-112» (п. 3.17 единого документа)

**Общие:**

| Комбинация | Действие |
|------------|----------|
| Alt (зажатие) | Отображение подсказок по комбинациям клавиш |
| Insert | Создать новую карточку |
| Esc | Закрыть карточку / всплывающее окно |
| Tab / Shift+Tab | Переход вперёд/назад между полями и кнопками |

**Переход к блокам карточки (режим создания):**

| Комбинация | Действие |
|------------|----------|
| Alt+F1 / Alt+F2 / Alt+F3 | К блокам телефонных номеров |
| Alt+K | К блоку «Канал связи» |
| Alt+Q | К блоку заявителя |
| Alt+A | К блоку «Адрес» |
| Alt+P | К блоку пострадавших |
| Alt+N | К блоку «Нет контакта / Срыв звонка» |
| Alt+T | К блоку «Что случилось» |
| Alt+R | К блоку значимого типа происшествия |
| Alt+O | К блоку описания |
| Alt+Z | К блоку управления службами |
| Alt+1…n | К блокам добавленных опросных карт (напр. Alt+1) |
| Alt+Ctrl+1…n | К определённым вопросам в опросных картах |

**Мгновенные действия (режим создания):**

| Комбинация | Действие |
|------------|----------|
| Alt+S | Сохранение карточки |
| Alt+W | Создание связи |
| Alt+B | Создание напоминания |
| Alt+V | Указание происшествия как важного |
| Alt+M | Создание сообщения об ошибке |

**Режим просмотра:**

| Комбинация | Действие |
|------------|----------|
| Alt+O | К блоку отработок |
| Shift+F1 | Пункт меню «Просмотр» |
| Shift+F2 | Пункт меню «Дополнить» |
| Alt+S | «Отработана» / «Завершить» (по статусу карточки) |
| Alt+W | Создание связи |
| Alt+B | Создание напоминания |
| Alt+V | «Важное происшествие» |
| Alt+Y | «Проверена» (в статусе Проверена) |
| Alt+N | «Вернуть на доработку» (в статусе Проверена) |

**Окно добавления связи:**

| Комбинация | Действие |
|------------|----------|
| Alt+1 | К блоку поиска происшествия |
| Alt+2 | К блоку списка происшествий |
| Alt+3 | К кнопке возврата |

## Критерии приёмки

- Курсант видит полную историю своих попыток с расшифровкой оценок и ошибок.
- Нельзя получить чужие результаты ни через UI, ни через мок-API (фильтр по `studentId`).
