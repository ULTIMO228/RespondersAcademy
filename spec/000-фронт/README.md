# Фича 000-фронт — спецификации тестового фронтенда тренажёра оператора ДДС

> **Статус: ✅ завершена** (волны 0–5, 283 задачи — `12-tasks.md`; доказательства сдачи — `docs/FINAL-GATE.md`, `docs/DELIVERY.md`).
> Этот пакет — первая фича проекта (`spec/000-фронт/`); реестр фич и правила нумерации — `spec/README.md`. Новые фичи оформляются отдельными папками `spec/NNN-имя/`.

Пакет указаний для разработки **тестовой системы с тестовым фронтом на мок-данных**: эмулятор АРМ-112 для подготовки операторов ДДС г. Москвы (хакатон «Лидеры цифровой трансформации», задача № 9).

Стек-ориентир: **Next.js (App Router) + TypeScript**. Роли: Обучающийся (диспетчер ДДС), Преподаватель, Администратор. Язык: русский.

## Жёсткие правила (кратко)

- **Дизайн**: точная реплика 1:1 («тютелька в тютельку») по референс-скриншотам ПОВ-112/АРМ-112 (`hack/Фронт/images/`, `hack/Фронт/Источники/скриншоты_из_docx/`, `research/arm-112/screenshots/`). Новые тренажёрные элементы — только в той же палитре и тех же токенах, изменения незаметны. Дизайны из «карты проекта» — только пожелания. Подробности — `07-design-guidelines.md`.
- **Контур**: локальный, без внешних сетей и CDN; все данные — синтетические моки.
- **ИИ**: в тестовом фронте имитируется моками, в UI — бейдж «ИИ»; приоритет оценки — за преподавателем.
- **Нормативы**: реакция 30 сек, отработка 3 мин; полный жизненный цикл статусов реагирования обязателен.
