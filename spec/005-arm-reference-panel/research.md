# Research: Справочник в АРМ (005)

Все вопросы технического контекста закрыты по коду репозитория (2026-10-19).

## R1. Источник статей
- **Decision**: существующий `GET /api/v1/kb/articles` (105 статей, `KbArticle` в `src/shared/api/types/kb.ts`), загрузка всех статей один раз при первом открытии панели, поиск — на клиенте.
- **Rationale**: 105 коротких статей — десятки КБ; страница `/reference` уже грузит их целиком (`referenceApi.articles`). Правки преподавателя (PATCH) видны при следующей загрузке (FR-005) — кэш живёт только пока открыта страница АРМ, при повторном открытии статьи — повторный `GET /kb/articles/{id}`.
- **Alternatives**: серверный поиск через `?q=` — сейчас ищет только подстроку в названии и группе, без тезисов и основ; переделка не окупается.

## R2. Поиск по основам слов (FR-003)
- **Decision**: собственная функция в `src/shared/lib/kb-search`: нормализация (нижний регистр, `ё→е`, только буквы/цифры), отсечение типовых русских окончаний (простой стеммер «snowball-lite»: список окончаний по убыванию длины, основа ≥ 3 букв), совпадение по префиксу основы. Вес: название ×3, группа ×2, тезисы ×1; статья попадает в выдачу, только если найдены **все** слова запроса. Подсветка — по найденным основам в названии и тезисах.
- **Rationale**: локальный контур (конституция I), без новых пакетов (YAGNI); опечатки не исправляем (решение владельца).
- **Alternatives**: пакет `snowball-stemmers`/`lunr` — новая зависимость ради 105 статей; ИИ-поиск — против решения владельца.

## R3. Где хранить настройку «Справочник доступен»
- **Decision**: ключ `referenceAllowed: boolean` в `Assignment.params` (JSON, без миграции). Отсутствие ключа (старые задания) = значение по умолчанию формата: тренировка — `true`, экзамен — `false`. Сервер при создании всегда записывает явное значение.
- **Rationale**: `params` уже хранит `hints`, `timeLimitSec`, `passThreshold`; поле в `AssignmentParams` добавляется — контракт расширяется только добавлением (AGENTS §2).
- **Alternatives**: отдельная колонка — миграция ради одного флага.

## R4. Серверный запрет во время попытки (FR-008)
- **Decision**: сервис `reference_access.lock_for(db, student_id)` ищет связи `AssignmentAttempt` обучающегося в состоянии `ringing`/`answered` по активным заданиям с эффективным `referenceAllowed = false`; для экзамена с `timeLimitSec` сначала вызывается существующий `_expire` (вышедшее время → `notCompleted`, замок снимается). Если замок есть — `GET /kb/articles` и `GET /kb/articles/{id}` отвечают обучающемуся **403 `forbidden`** «Справочник недоступен в этом задании». Новый `GET /api/v1/me/reference-access` → `{allowed, assignmentId?, message?}` для панели и кабинета. Преподаватель и администратор не блокируются.
- **Rationale**: попытка — единственное, что связывает обучающегося с заданием на сервере; «уже открытая попытка доигрывается со значением на момент начала» выполняется автоматически, т. к. параметр задания после создания не меняется (редактирования заданий в API нет).
- **Alternatives**: проверка только в UI — нарушает FR-008.

## R5. Где разместить кнопку и панель (FR-001, FR-012)
- **Decision**: `widgets/simulator-bar` — единственное тренажёрное добавление над `/arm/*` (оба режима: `ArmSectionLayout` для «Специалист-112», `GuardedThemeLayout` для журнала и карточки ДДС). В панель добавляется кнопка «Справочник», открывающая новый виджет `features/arm-reference` (выдвижная панель справа, `role="dialog"`, `aria-modal="false"`, Esc и возврат фокуса). Панель — поверх содержимого, не размонтирует страницу — состояние карточки и таймеры не трогаются.
- **Alternatives**: модальное окно с затемнением — перекрывает карточку, противоречит истории 1.

## R6. Отдельное окно (FR-006)
- **Decision**: новый роут `/arm/reference-window?q=…&article=…` без меню кабинета (только поиск + статья), открывается `window.open(url, "arm-reference", "popup,width=720,height=900")`. Окно периодически (раз в 15 с и при фокусе) запрашивает `/me/reference-access`; при `allowed=false` скрывает содержание.
- **Rationale**: тот же виджет, другая обёртка; проверка на сервере всё равно действует.

## R7. Аудит (FR-010)
- **Decision**: существующая запись аудита создания задания (`assignment_service._audit`) дополняется текстом «справочник: доступен/недоступен». Редактирования задания в API нет — отдельная запись изменения не нужна.

## R8. Влияние на оценку (FR-011)
- **Decision**: панель не пишет событий попытки; оценщик не трогается.

## Уточнения при реализации (2026-10-19)
- Замок отдаёт стандартный `403 forbidden` с текстом «Справочник недоступен в этом задании» — без нового кода ошибки (перечень `ApiErrorCode` не расширяется); причину панель берёт из `/me/reference-access`.
- Окно для второго монитора — `/arm/reference-window`: вне лэйаута кабинета (без меню), под гвардом `/arm`.
- Панель живёт в слое `features/arm-reference`: виджет `simulator-bar` не может импортировать другой виджет (Steiger, FSD).
