# Feature Specification: Справочник в тренажёре — панель поверх АРМ с поиском и доступом по решению преподавателя

**Feature Branch**: `005-arm-reference-panel` (отдельная ветка не создавалась; работа ведётся в `fix/tz-audit`)

**Created**: 2026-10-19

**Status**: Draft

**Input**: User description: "Справочник в тренажёре отдельным окном (идея из Obsidian «ддс/идеи»). Ученик во время работы в АРМ (оба режима: «Специалист-112» и «ДДС») открывает справочник выдвижной панелью поверх АРМ, не уходя с карточки; в панели есть ссылка «открыть в новом окне» для второго монитора. Поиск по ключевым словам; материал показывается тезисно (ключевые пункты сверху), источник — существующие 105 статей справочника (по группам ЕКП), новый контент не пишем. Учитель решает, можно ли пользоваться справочником на занятии: галочка «Справочник доступен» в мастере назначения; в тренировке по умолчанию включена, в экзамене выключена; учитель может поменять. Основание ТЗ: обучающийся «просматривать инструкции и методические материалы (справочную базу)»; преподаватель настраивает обучение. Не выходить за рамки ТЗ."

## Контекст

ТЗ (роль «Обучающийся») требует «просматривать инструкции и методические материалы (справочную базу)», а роль «Преподаватель» — «настраивать критерии успешности» и параметры заданий. Справочник уже есть: 105 статей по группам происшествий классификатора ЕКП, у каждой — короткие списки «признаки», «оповещение служб», «что уточнить», «решение ДДС», «типичные ошибки»; есть поиск, преподаватель может править статьи. Но во время отработки обучающийся попадает в справочник только переходом на отдельную страницу — карточка и таймеры уходят с экрана. И преподаватель не может запретить справочник на экзамене: в задании есть только переключатель «Подсказки».

Фича не создаёт нового содержания и не меняет сами статьи: она делает существующий справочник доступным прямо в рабочем месте и даёт преподавателю решать, когда им можно пользоваться.

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Найти ответ, не уходя с карточки (Priority: P1)

Обучающийся отрабатывает вызов в АРМ (режим «Специалист-112» или «ДДС»), сомневается, какие службы оповестить при «пожаре на балконе». Нажимает «Справочник» — справа выдвигается панель, карточка и таймеры остаются видны. Вводит «балкон пожар», видит подходящие статьи, открывает нужную и читает тезисы: признаки, кого оповестить, что уточнить у заявителя. Закрывает панель и продолжает с того же места — введённые в карточку данные не потеряны.

**Why this priority**: это и есть требование ТЗ — доступ к справочной базе во время выполнения практических заданий; без него справочник бесполезен в момент, когда нужен.

**Independent Test**: открыть билет в тренировке, открыть панель, найти статью по ключевому слову, закрыть панель — убедиться, что таймер шёл, а поля карточки сохранились.

**Acceptance Scenarios**:

1. **Given** открыта карточка в АРМ (любой из двух режимов) и справочник разрешён, **When** обучающийся нажимает «Справочник», **Then** открывается панель поверх АРМ, карточка и таймеры остаются видимыми и продолжают работать.
2. **Given** панель открыта, **When** обучающийся вводит одно или несколько слов («газ квартира»), **Then** показываются статьи, где эти слова встречаются в названии или тезисах, самые подходящие — сверху, найденные слова подсвечены.
3. **Given** найдена статья, **When** обучающийся её открывает, **Then** видит название и тезисы списками в порядке: признаки → оповещение служб → что уточнить → решение ДДС → типичные ошибки; ключевые пункты видны без прокрутки.
4. **Given** панель открыта и в карточке введён текст, **When** обучающийся закрывает панель (кнопкой или клавишей Esc), **Then** возвращается к карточке, введённое сохранено, фокус возвращается туда, где был.
5. **Given** ничего не найдено, **When** результат пуст, **Then** выводится «Ничего не найдено» и подсказка изменить запрос; панель не закрывается.

### User Story 2 — Преподаватель решает, можно ли пользоваться справочником (Priority: P1)

Преподаватель создаёт задание в мастере назначения. На шаге параметров видит галочку «Справочник доступен». Для тренировки она включена по умолчанию, для экзамена — выключена. Преподаватель может изменить её в любую сторону. На экзамене со снятой галочкой у обучающегося нет ни кнопки «Справочник», ни возможности открыть справочник иным путём во время попытки.

**Why this priority**: без контроля доступа справочник на экзамене превращается в шпаргалку и обесценивает оценку; это прямая настройка обучения, которую ТЗ отдаёт преподавателю.

**Independent Test**: создать экзамен с выключенным справочником и тренировку с включённым; войти обучающимся и убедиться, что в экзамене справочника нет (и прямой переход к нему во время попытки не работает), а в тренировке — есть.

**Acceptance Scenarios**:

1. **Given** мастер назначения, формат «Тренировка», **When** преподаватель доходит до параметров, **Then** галочка «Справочник доступен» включена.
2. **Given** мастер назначения, формат «Экзамен», **When** преподаватель доходит до параметров, **Then** галочка выключена; при смене формата значение по умолчанию меняется, пока преподаватель не изменил его вручную.
3. **Given** задание создано, **When** преподаватель открывает его карточку или шаг «Проверка и создание», **Then** видно, доступен ли справочник.
4. **Given** экзамен со справочником «выключен», **When** обучающийся работает с билетом этого экзамена, **Then** кнопки «Справочник» нет, а попытка открыть справочник другим путём (из меню кабинета, прямой ссылкой, клавиатурой) во время попытки показывает «Справочник недоступен в этом задании».
5. **Given** справочник выключен, **When** попытка завершена (билет отправлен или время вышло), **Then** справочник снова доступен обучающемуся в кабинете как обычно.

### User Story 3 — Справочник на втором мониторе (Priority: P2)

Рабочее место оператора — два-три монитора. Обучающийся в панели нажимает «Открыть в новом окне», переносит окно справочника на второй монитор и пользуется им параллельно с карточкой. Правила доступа те же, что для панели.

**Why this priority**: удобство на целевом рабочем месте (спека 000: ПК с 2–3 мониторами), но без него ядро истории 1 работает.

**Independent Test**: из панели открыть справочник в новом окне, выполнить поиск и чтение статьи там; в экзамене с выключенным справочником новое окно открыться не должно.

**Acceptance Scenarios**:

1. **Given** панель открыта, **When** нажато «Открыть в новом окне», **Then** справочник открывается в отдельном окне браузера с тем же запросом и статьёй, без меню кабинета — только поиск и статья.
2. **Given** справочник в новом окне, **When** обучающийся работает в АРМ в основном окне, **Then** карточка не перезагружается и таймеры не сбрасываются.
3. **Given** задание со справочником «выключен», **When** окно справочника уже было открыто до начала попытки, **Then** на время попытки в нём показывается «Справочник недоступен в этом задании».

---

### Edge Cases

- **Свободная тренировка без задания** (обучающийся открыл АРМ сам): справочник доступен — это тренировка.
- **Цепочка 112 → ДДС**: настройка задания действует на оба этапа.
- **Задание изменено во время прохождения**: новое значение действует со следующего открытия билета; уже открытая попытка доигрывается со значением на момент её начала.
- **Нет подходящей статьи**: поиск честно показывает «Ничего не найдено», пустых статей не показываем.
- **Очень короткий запрос** (одна-две буквы): поиск не запускается, подсказка «Введите хотя бы 3 буквы».
- **Другая форма слова** («газа», «пожаре»): находится по основе слова. Опечатки («пажар») не исправляются; при пустом результате — подсказка проверить написание.
- **Справочник недоступен из-за ошибки сервера**: панель показывает «Справочник временно недоступен», работа с карточкой не прерывается.
- **Преподаватель или администратор в АРМ** (просмотр, режим «делай как я»): справочник им доступен всегда.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: В АРМ (оба режима — «Специалист-112» и «ДДС») MUST быть кнопка «Справочник», открывающая панель поверх рабочего экрана без ухода с карточки; карточка, введённые данные и таймеры MUST продолжать работать.
- **FR-002**: Панель MUST закрываться кнопкой и клавишей Esc с возвратом фокуса туда, где он был; открытие и закрытие MUST NOT сбрасывать введённые данные.
- **FR-003**: Поиск MUST находить статьи по одному или нескольким ключевым словам в названии и тезисах, без учёта регистра и «ё/е», с учётом формы слова (основа); результаты MUST упорядочиваться по совпадению, найденные слова — подсвечиваться. Поиск запускается от 3 букв.
- **FR-004**: Статья MUST показываться тезисно: название, затем списки «Признаки», «Оповещение служб», «Что уточнить у заявителя», «Решение ДДС», «Типичные ошибки»; пустые разделы MUST NOT показываться.
- **FR-005**: Источник содержания MUST быть существующий справочник (статьи по группам ЕКП); фича MUST NOT создавать и менять статьи. Правки преподавателя в справочнике MUST быть видны в панели при следующем открытии статьи.
- **FR-006**: Из панели MUST открываться справочник в отдельном окне с тем же запросом и статьёй; отдельное окно показывает только поиск и статью.
- **FR-007**: В мастере назначения MUST быть настройка «Справочник доступен»: по умолчанию включена для тренировки и выключена для экзамена; преподаватель MUST иметь возможность изменить её для любого формата; значение MUST быть видно на шаге проверки и в карточке задания.
- **FR-008**: Если в задании справочник выключен, во время попытки по билету этого задания обучающемуся MUST NOT быть доступно содержание справочника ни в панели, ни в отдельном окне, ни в кабинете, ни прямой ссылкой — показывается «Справочник недоступен в этом задании». Запрет MUST действовать на стороне сервера, а не только скрываться в интерфейсе.
- **FR-009**: Вне попытки с запретом (свободная тренировка, тренировка со справочником, после завершения экзамена) справочник MUST быть доступен обучающемуся как раньше.
- **FR-010**: Создание задания с настройкой «Справочник доступен» и её изменение MUST попадать в журнал аудита (кто, когда, задание, значение) — это настройка критериев успешности (ТЗ, роль «Преподаватель»).
- **FR-011**: Использование справочника во время попытки MUST NOT влиять на автоматическую оценку.
- **FR-012**: Интерфейс панели MUST быть на русском, оформлен в стиле АРМ (тренажёрные добавления незаметны — правило аутентичности `spec/000-фронт/07-design-guidelines.md`), управляем с клавиатуры, с подписями для скринридера.

### Key Entities

- **Статья справочника** (существует): группа происшествий ЕКП, название, тезисы по разделам. Фичей не меняется.
- **Параметр задания «Справочник доступен»** (новый): да/нет; значение по умолчанию зависит от формата задания (тренировка/экзамен); хранится в параметрах задания наряду с подсказками и лимитами.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Обучающийся находит статью по группе происшествия и открывает её тезисы не более чем за 15 секунд с момента нажатия «Справочник».
- **SC-002**: Для 10 типовых запросов из билетов («балкон пожар», «запах газа квартира», «ДТП пострадавшие» и т. п.) нужная статья оказывается в первой тройке результатов в 9 случаях из 10.
- **SC-003**: Открытие и закрытие панели ни в одном из 20 проверочных прогонов не сбрасывает введённые в карточку данные и не останавливает таймеры.
- **SC-004**: В экзамене со справочником «выключен» ни один из способов открыть справочник (панель, отдельное окно, меню кабинета, прямая ссылка) не показывает содержание статей во время попытки — 0 из 4.
- **SC-005**: Преподаватель меняет доступность справочника в задании одним действием на шаге параметров; значение по умолчанию верно для 100 % новых тренировок и экзаменов.

## Assumptions

- «Отдельное окно» из идеи — это выдвижная панель поверх АРМ плюс «Открыть в новом окне» для второго монитора (решение владельца 19.10.2026).
- «Тезисно» — существующие разделы статей, показанные короткими списками; новое содержание не пишется (решение владельца). Поиск — по основам слов, без исправления опечаток и без ИИ (локальный контур, конституция I).
- Доступ задаётся в задании: тренировка — включён по умолчанию, экзамен — выключен (решение владельца). Переключение «на лету» во время идущего занятия — вне рамок.
- Свободная отработка вне задания считается тренировкой — справочник доступен.
- Статистика «кто и сколько раз открывал справочник» для преподавателя — вне рамок.
- Мобильная версия — вне рамок (ТЗ §6, опционально); целевое место — ПК с 1920 px и шире.
- Права доступа к справочнику для преподавателя и администратора не меняются.
