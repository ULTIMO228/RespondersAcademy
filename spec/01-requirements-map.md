# 01. Матрица трассировки требований

Каждый пункт ТЗ (`extracted.txt`) и Q&A → где закрыт в спецификациях и моках. Формат: требование → документ/страница/мок. Статусы: **С** — специфицировано; **М** — покрыто мок-данными; **О** — опционально (ТЗ §6), помечено этапом 2.

Источники фактов вне ТЗ (используются в ссылках ниже): `hack/Фронт/МОКИ-ДАННЫЕ.md` — норматив мок-данных; `hack/Фронт/ПРАВИЛА-КОДА-ФРОНТ.md` — нормы кода фронта (FSD + SOLID), учтены в `03-architecture.md`; `hack/Фронт/ФРОНТ-АРМ-112-ЕДИНЫЙ-ДОКУМЕНТ.md` — UI-факты из памятки и скриншотов; `research/arm-112/docs/` — `FIELDS.md`, `INTERFACE.md`, `MOSCOW-112.md`, `BRAND-AND-SOURCES.md` (поля, структура интерфейса, нормативы Москвы, айдентика).

## ТЗ §16–17. Критерии экспертиз (что показываем жюри)

| Критерий | Как закрываем |
|---|---|
| UX/UI: интуитивность, логически связанные блоки рядом | компоновка по реальному АРМ-112 + `07-design-guidelines.md` |
| Объективность диаграмм | графики строятся строго по `reports.json` (`13-teacher-reports.md`) |
| Рекомендации сервиса соответствуют реальным | инсайты/подсказки — из домена памятки (статусы, нормативы) |
| Настраиваемые параметры | веса оценки, тайминги, критерии успешности (`11/12`) |
| Проверка работы расчётов | сверка баллов и таймингов отчёта с `reports.json`: таблица, графики и экспорт строятся из одного мока (`13-teacher-reports.md`) |
| Проверка прогнозирования (оценка достоверности) | «прогнозирование» = адаптивная сложность (Q&A в10): стратегия `cardFlow` adaptive в `12-teacher-session.md` + `05-data-models.md` — сложность растёт/снижается по последним оценкам |
| Качество кода | нормы кода фронта — `hack/Фронт/ПРАВИЛА-КОДА-ФРОНТ.md` (FSD + SOLID), учтены в `03-architecture.md` |
| Возможность интеграции в любые другие системы | замена data-access слоя без смены контрактов (`03-architecture.md`, `05-data-models.md`); внутренний API (§6) |
| Скорость работы решения | декларации §7 + мок-индикация в `21-admin-system.md` и `13-teacher-reports.md` |
| Полнота сопроводительной документации | см. раздел §13–14, §18 ниже |
| Питч-сессия (выступление коллектива) | демо-путь `06-user-flows.md` (≤ 5 мин) + скринкаст со звуком (Q&A в12) |
