# spec/ — реестр фич

Каждая фича — отдельная папка `NNN-короткое-имя/`. Номер сквозной, выдаётся по порядку
постановки фичи; новая фича получает следующий свободный номер (после слияния веток, фича 021, — 022).
Состав пакета внутри папки — по образцу `000-фронт/`: обзор, карта требований, роли, архитектура,
спеки страниц, модели данных, пользовательские потоки, дизайн-правила, решения Q&A, глоссарий,
правила кода, план реализации, задачи, мок-данные.

Счётчики `[X]/[ ]` взяты из `tasks.md` фичи на вершине её исходной ветки (2026-10-20) без пересчёта и без новой проверки. Колонка «Ветка / прежний номер» нужна, чтобы авторы веток нашли свою фичу после перенумерации (слияние 021, `research.md` R2).

## Мок-данные

Рабочие моки приложения генерируются из спек-моков: `npm run mocks:sync` копирует
`spec/000-фронт/mocks/` в `mocks/` (и `icons/` в `public/icons/`); доменный валидатор —
`npm run mocks:validate`. Код приложения обращается только к `mocks/` через алиас
`@mocks/*`, к `spec/` — никогда.
