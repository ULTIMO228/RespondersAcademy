# Чек-лист сверки «один в один»: окна обучающегося-112 (009, SC-001, SC-002)

**Как сверять**: пара скриншотов 1920×1080, «референс / наш экран», рядом. Попиксельное совпадение не требуется (007, Clarifications). Цвета — замером пикселя со скриншота того же экрана и в том же состоянии карточки (research R7a, R13a), не на глаз.
**Референсы**: `hack/Фронт/Источники/скриншоты_из_docx/` (КАРТОЧКА_*, ИНСТРУКЦИЯ_*, ДДС_*), каталог `окна-АРМ-112.html` (номера окон ниже — по нему).
**Пункты для каждого окна**: Б — блоки и их порядок/место; Н — надписи дословно; Ц — цвета; З — значки; Л — нет лишнего (учебное только в полосе тренажёра).
Отметка: `✅ дата` или `❌ дата: что не так` — по каждому пункту. Окно считается сверенным, когда все пять пунктов ✅.

Окно 1 «Вход в систему» — область 007 (US5), здесь не сверяется. Окна 10, 11, 14–18 в режиме 112 не моделируются (реестр spec.md).
