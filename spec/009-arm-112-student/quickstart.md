# Quickstart: проверка АРМ специалиста-112 (009)

## Подготовка

```bash
npm ci && (cd backend && uv sync --group dev)
npm run mocks:sync && npm run mocks:validate        # после правок cards.json (channel/smsText/repeatOf/lockedBy)
cd backend && uv run python -m app.seed.load --reset # только с разрешения владельца; затем alembic head = 0007
cd .. && ./scripts/demo-up.sh                         # фронт :3130, бэкенд :8130
```

Автопроверки: `npm run check`, `npm run test`, `cd backend && uv run pytest -q && uv run ruff check .`, `npx playwright test e2e/arm-112-visual.spec.ts` (снимки 1920×1080).

## Ручные сценарии (под ivanov, окно 1920×1080)

Результат отмечать здесь же: ✅ / ❌ + дата. Сверка — по [checklists/visual-112.md](checklists/visual-112.md) и референсам `hack/Фронт/Источники/скриншоты_из_docx/`, каталогу `окна-АРМ-112.html`.

1. **Журнал (US1)**: «Открыть» тренировку 112 → журнал как ИНСТРУКЦИЯ_106; меню, кроме «журнал», неактивно; меню платформы и «Режим «Специалист-112»» нет; вкладка браузера «Поиск происшествий».
2. **Входящий звонок (US2)**: окно «Входящий звонок · с номера …» поверх затемнённого журнала; «×» → строка в очереди, клик → окно снова; «Принять» → карточка, таймер 00:00, вкладка «Происшествие N», звучит заявитель.
3. **SMS (US2)**: билет с `channel: sms` → окно «Входящее сообщение · Источник - СМС»; в карточке канал «СМС»; «список SMS» → «История сообщений» с текстом.
4. **Карточка (US3)**: блоки и подписи — КАРТОЧКА_1; таймер красный после 01:00; «что случилось?» → подсказки ЕКП → вкладка «Происшествие …» с чипами; вторая вкладка; закрыть вкладку крестиком.
5. **Адрес (US3)**: Москва — округ → район → улица; Московская область — Субъект/Населённый пункт/Объект/Описательный адрес вручную; «очистить адрес»; карта — точка ставит координаты, без сетевых запросов (DevTools → Network).
6. **Службы (US4)**: признаки → автоматические плитки без удаления; «+» → «Добавьте службы», поиск, «Сохранить и закрыть»; ручную убрать «×»; «⇕»; «сохранить» → подтверждение оповещения → результат.
7. **Нет контакта / срыв (US3)**: карточка сохраняется без адреса и типа; оценка не падает.
8. **Повторный звонок (US5)**: билет с `repeatOf` → окно «Есть карточка с заявителем по этому номеру» → «привязать» → «связана» в карточке, цепочка в журнале; «Показ связей» → «отвязать», «сделать главной»; в разборе — замечание при неверной привязке.
9. **Служебные окна (US6)**: напоминание на 1 мин → окно ИНСТРУКЦИЯ_100, все 4 действия, данные карточки целы; фоновая карточка с `lockedBy` → окно блокировки, правка запрещена; «?» / Alt+M → «Сообщить о проблеме» → у преподавателя группы на `/teacher` новое сообщение.
10. **Учебное только в полосе (SC-002)**: норматив, лимит, «Справочник», «В кабинет», подсказки, аварийный транскрипт — только в полосе тренажёра.
11. **Старые попытки (FR-033, SC-006)**: результаты прежних попыток 112 в `/student/results` и у преподавателя открываются без ошибок.
12. **SC-004**: 5 эталонных прогонов 112 — баллы до/после (таблица в `baseline.txt` по образцу 008); эталонных прогонов нет — пометить «не проверено», не выдумывать.
13. **Клавиатура (FR-032)**: Shift+F1, Shift+F2, Alt+E, Alt+A, Alt+T, Alt+M, Enter работают; у кнопок-значков есть `aria-label`.
