**Tests**: обязательны — TDD по `CLAUDE.md`: сначала красный тест по правильной причине, затем код; для каждого отказа 400/401/403/404 — парный запрос, который обязан вернуть 200/201.

## Format: `[ID] [P?] [Story] Description`

- **[P]** — можно делать параллельно (другие файлы, нет зависимости от незакрытых задач)
- **[USn]** — история из spec.md
- `[X]` ставится только после реальной проверки; частичное — оставлять открытым с пометкой, что сделано.

## Path Conventions

Веб-приложение в одном репозитории: фронт — `src/` (FSD) и `app/` (тонкие роуты), бэкенд — `backend/app/`, `backend/ml/`, тесты бэкенда — `backend/tests/{unit,integration,contract}/`, тесты фронта — рядом с кодом (`*.test.ts(x)`), e2e — `e2e/`.

После каждой фазы: `npm run check`, `npm run test`, `cd backend && uv run pytest -q && uv run ruff check .`, отдельный коммит (Conventional Commits, по-русски, без подписей агента).
