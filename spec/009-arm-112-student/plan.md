# План: АРМ специалиста-112 один в один (009)

**Spec**: `spec/009-arm-112-student/spec.md` · **Ветка**: `SASHA` · **Дата**: 2026-10-20

## Цель

Перевести рабочее место ученика-112 (`/arm/operator112`) с «формы тренажёра» на раскладку карточки ПОВ-112 по
КАРТОЧКА_image1–3 и окну «Входящий звонок» (ИНСТРУКЦИЯ_4). Методика, оценка и контракты API не меняются.

## Этапы

| Этап | Истории / FR | Что | Контракт |
|---|---|---|---|
| A (эта сессия) | US2 (FR-009), US3 (FR-012…FR-017 частично), US4 (FR-018…FR-021), FR-002, FR-003 | карточка ПОВ-112, окно «Входящий звонок», оранжевая панель «Службы:», окно «Добавьте службы», подтверждение сохранения, учебное — в полосу тренажёра | без изменений |
| B | FR-014/FR-023 расширенный адрес, FR-017 «нет контакта»/«срыв звонка», удаление ручной службы, несколько типов | поля Страна/Субъект/Нас. пункт/Объект/Корпус/…, пустая карточка, событие `serviceRemoved`, несколько вкладок типов | **меняется** (`CardDraftAddress`, `OperatorEventType`, бэкенд `operator112_service`, оценщик) |
| C | US1 (журнал ученика-112), US5 (повторный звонок, связи), US6 (SMS, блокировка, напоминание, «Сообщить о проблеме»), FR-015 окно карты | новые окна | частично |

## Решения этапа A

- **Маршрут**: `/arm/operator112` переезжает в группу `app/arm/(operator112)` с лэйаутом `ArmOperator112Layout`: полоса тренажёра без шапки `AppNav` (FR-003). URL не меняется.
- **Полоса тренажёра**: `SimulatorBar` получает слот `#simulator-bar-slot`; экран 112 выводит туда лимит билета, норматив ответа/отработки, отметку «ответ позже норматива» и подсказку тренировки через `SimulatorBarPortal` (FR-002).
- **Таймер шапки**: «ММ:СС минут секунд», стартует при «Принять» (`answeredAt`), до ответа — 00:00; тёмный фон до 60 с, красный после. Источника порога в памятке нет — по умолчанию спеки 1 минута (FR-013, Assumptions).
- **Окно вызова**: синее «Входящий звонок · с номера +7 (XXX) XXX-XX-XX · Принять · ×». «×» прячет окно, вызов остаётся в очереди (Assumptions спеки); кнопка-трубка полосы телефонии мигает и снова открывает окно.
- **Запись заявителя**: голос проигрывается после «Принять» без видимого плеера; «записи звонков» открывает окно записи (повтор в тренировке, запрет в экзамене). В аварийном режиме (нет аудио) окно записи открывается само и показывает транскрипт — иначе ученик не узнает, что сказал заявитель.
- **Статус заявителя**: выпадающий «выберите статус» со значениями учебного набора (очевидец, пострадавший, родственник, знакомый, участник — `cards.json`); перечень боевого АРМ не известен. Два соседних выпадающих и кнопка перевода — неактивны.
- **Адрес**: рабочие поля этапа A — Улица (подсказка справочника), Дом/Вл., Округ, Район, Описательный адрес; Субъект показан «Москва»; Страна, Населённый пункт, Объект, Корпус, Стр/соор, Квартира/офис, Подъезд, Этаж, Код — неактивны до этапа B (иначе введённое терялось бы молча). Кнопка карты неактивна до этапа C. «×» строки адреса и «очистить адрес» очищают адрес.
- **Подпись источника адреса** («из справочника/вручную») с экрана убрана — в АРМ её нет; источник по-прежнему уходит в событии и карточке.
- **ЧС/ЧП** на карточке 112 нет (КАРТОЧКА_1); оценщик штрафует только за лишний флаг (`ml/assess/operator112.py:317`), поэтому без флажков балл не теряется.
- **«что случилось?»**: ввод фильтрует группы ЕКП; быстрые типы с соответствием в классификаторе (ДТП → «Дорожно-транспортные…», «Человек в опасности», «Консультация» → «Справочно-консультационная помощь») подставляют запрос, без соответствия — неактивны. Выбор группы создаёт вкладку с её названием и «×»; признаки — блоками чипов (заголовки уровней ЕКП «112-Признак.N», семантических заголовков референса в классификаторе нет). Тип один; второй выбор заменяет вкладку (несколько типов — этап B).
- **Службы**: плитки = `notification-list.services` (обязательные + добавленные); «×» на плитках неактивна (у автоматических удаление запрещено FR-019, удаление ручной — этап B). «+» открывает «Добавьте службы»: поиск, выбранные синие, доступные к выбору — условные службы списка; «Сохранить и закрыть» шлёт `serviceAdded`. «⇕» разворачивает панель. Значки связи/таймера/руки/колокола/сообщения/закрыть — неактивны до этапа C.
- **«сохранить»**: окно подтверждения «Оповестить службы и сохранить карточку?» → прежняя передача `submit` (контракт, оценка, разбор — без изменений).
