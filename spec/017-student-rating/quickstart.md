# Quickstart: проверка фичи 017

Стенд: `git-backend` (:8000), `git-front` (:3000). У `morozova` должны быть закрепления групп (на старой базе — назначить в `/admin/users`, дефект 5.3). Демо-набор карты ошибок (`seed_error_map_demo.py`) даёт группы с попытками.

## Автотесты
```bash
cd backend && uv run python -m pytest -q tests -k "student_rating or student_stats or profile"
npx vitest run src/pages/teacher/rating src/pages/teacher/students
```

## Сценарии
1. **Таблица (US1)**: morozova → «Рейтинг» → своя группа; сортировка по «Реакция» и обратно; режим «ДДС» — числа пересчитаны; ученик с < 3 попытками — «мало данных» без места; реакция > 30 с выделена значком и подписью.
2. **Профиль (US2)**: клик по строке → разделы баллов, скорости, динамики, слабых этапов, ошибок, рекомендаций, попыток; «Назад к рейтингу» — та же сортировка; «Назначить тренировку» — мастер с отмеченным учеником.
3. **Права (US3)**: kovalev → `/teacher/students/<ученик Морозовой>` → «Нет доступа»; `GET /api/v1/teacher/rating?groupId=<чужая>` → 403; ivanov → `/teacher/rating` → `/forbidden`, API → 403; vinogradova → «Нет закреплённых групп».
4. **Сверка (SC-002)**: средний балл ученика в рейтинге = среднее баллов в его списке попыток.
