# Quickstart: проверка фичи 016

Стенд: `git-backend` (:8000) и `git-front` (:3000) из `~/Desktop/ддс /.claude/launch.json` (или `./scripts/demo-up.sh`). Логины: `morozova/teacher112`, `ivanov/student112`.

## Автотесты
```bash
cd backend && uv run python -m pytest -q tests -k "reference_access or kb or assignment"
npx vitest run src/shared/lib/kb-search src/widgets/reference-panel src/features/assignment-create
```

## Сценарии
1. **Панель (US1)**: ivanov → тренировка → АРМ → «Справочник» → «балкон пожар» → открыть статью → тезисы в порядке признаки → оповещение → уточнить → решение ДДС → ошибки; Esc — карточка с введённым текстом на месте, таймер шёл.
2. **Доступ (US2)**: morozova → мастер, формат «Экзамен» — галочка выключена, «Тренировка» — включена; создать экзамен без справочника для ivanov. ivanov открывает билет экзамена → кнопки нет; `/reference` и `GET /api/v1/kb/articles` → «Справочник недоступен в этом задании» (403). После отправки билета — справочник снова доступен.
3. **Новое окно (US3)**: в тренировке «Открыть в новом окне» → окно с тем же запросом; во время экзамена с запретом окно показывает «недоступен».
4. **Аудит**: `/admin/audit` → запись создания задания содержит «справочник: недоступен».
