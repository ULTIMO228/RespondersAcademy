# 09. Глоссарий

Термины ТЗ (раздел 1) и доменной области. Используется единая терминология во всех документах `spec/` и в коде фронтенда (названия полей, подписи).

## Термины ТЗ

| Термин | Определение |
|---|---|
| АРМ | Автоматизированное рабочее место |
| АРМ-112 | Удалённый терминал системы-112, установленный в службе; через него диспетчер ДДС работает с карточками происшествий |
| ГБУ «Система 112» | Оператор системы-112 города Москвы |
| ДДС | Дежурно-диспетчерская служба — служба, принимающая и обрабатывающая вызовы от системы-112 |
| ИИ | Комплекс технологий, имитирующих когнитивные функции человека |
| Паттерн | Устойчивый шаблон поведения или последовательность событий |
| Тренажёр | ПО для обучения операторов с имитацией реальных ситуаций |
| Эмуляция | Имитация работы программного или аппаратного обеспечения |
| RBAC | Role-Based Access Control — разграничение доступа на основе ролей |
| SIP | Session Initiation Protocol — протокол VoIP-связи |
| VoIP | Voice over IP — передача голоса через IP-сеть |
| TLS/SSL | Криптографические протоколы защищённой передачи данных |
| СУБД | Система управления базами данных (в ТЗ — PostgreSQL 12+) |

## Доменные термины (по памятке «Работа на АРМ-112», ГБУ «Система 112», 2025)

| Термин | Определение |
|---|---|
| ПОВ-112 | Подсистема обеспечения вызова экстренных оперативных служб по единому номеру «112» в г. Москве (КИС УСС) — информационная система системы-112 Москвы. То, чей интерфейс эмулирует тренажёр |
| КИС УСС | Комплексная информационная система мониторинга и управления силами и средствами экстренных оперативных служб г. Москвы |
| Карточка происшествия (КП) | Основная единица данных: регистрация происшествия с адресом, типом, описанием, списком оповещения и статусами реагирования |
| УКИО | Унифицированная карточка информационного обмена — официальное название карточки происшествия (общая часть + характеристики служб). Словарь полей — `research/arm-112/docs/FIELDS.md` |
| УЧОЛ | Унифицированная часть опросного листа — карточка обращения (заполняется при опросе заявителя). В тренажёре не моделируется: точка A исключена (Q&A в8) |
| Опросная карта | Формализованный набор вопросов и типовых признаков, который заполняет оператор при регистрации происшествия |
| Типовые (формализованные) признаки | Признаки происшествия, выбираемые из дерева (3 уровня). Комбинация признаков определяет итоговый тип происшествия |
| Итоговый тип происшествия | Тип, однозначно определяемый комбинацией типовых признаков; ему соответствует список оповещения |
| ЕКП | Единый классификатор событий, происшествий и чрезвычайных ситуаций. Источник: `hack/Фронт/Источники/Классификатор_происшествий_v_046_24_корректировка_МВД_+_Департамент.xlsx` (v_046_24: 1283 записи, 105 групп — актуальная версия, заменяет v.046_11) |
| ЕКП-35 | Тип происшествия по классификатору ЕКП (колонка «ТИП происшествия ЕКП 35») |
| Список оповещения | Набор служб, автоматически оповещаемых о происшествии данного итогового типа. Формируется автоматически по ЕКП и полигонам; специалист-112 может добавить службу вручную, удалить — не может |
| ВИС | Внешняя информационная система (интегрированные службы: КИС УСС/МЧС-101, СОДЧ/МВД-102, КАСУ СМП-103, Система 104, ЦОДД, Мосводоканал, ЭРА-ГЛОНАСС, 112 МО, 112 Калужской обл.) |
| Главная служба | Приоритетная служба реагирования по ЕКП (колонка «Главная служба»: MCHS, Police, AMBULANCE, MOSGAZ и др.) |
| Статус реагирования | Отметка службы о ходе обработки: Добавлена / Получена службой / Принята / Не принята / Начало реагирования / Прибытие / Проведение работ / Работы завершены / Отказ от выполнения работ |
| Статус карточки | Этап жизненного цикла карточки: Зарегистрирована / Отработана / Проверена / Не оповещено / Отказ / Не завершено / Завершена |
| Отдел контроля (реагирования) | Подразделение Службы 112, следящее за корректностью и своевременностью работы служб |
| СТП | Служба технической поддержки ПОВ-112 (внешняя организация) |
| МГСЧС | Московская городская система предупреждения и ликвидации ЧС |
| Специалист-112 | Оператор Службы 112 ГБУ «Система 112», принимающий вызовы и создающий карточки |
| Диспетчер ДДС | Работник дежурно-диспетчерской службы, обрабатывающий поступившие карточки. **Целевая обучаемая роль тренажёра** |
| АОН | Автоматический определитель номера |
| ЭРА-ГЛОНАСС | Система экстренного реагирования при авариях; карточка создаётся автоматически |

## Нормативные основания (для справок в UI)

- ФЗ от 30.12.2020 № 488-ФЗ «Об обеспечении вызова экстренных оперативных служб по единому номеру "112"»
- ПП РФ от 12.11.2021 № 1931 (обязательные требования к системе-112, в т.ч. норматив 30 секунд на подтверждение приёма)
- ПП Москвы от 01.09.2020 № 1420-ПП (положение о системе-112 в Москве)
- Боевые нормативы времени ГБУ «Система 112» (`research/arm-112/docs/MOSCOW-112.md`): опрос заявителя — 1 мин; отправка карточки в службы — 30 сек; отметка ДДС о принятии карточки — ≤ 1 мин
- ФЗ № 149-ФЗ, ФЗ № 152-ФЗ (информация и персональные данные — требования ТЗ §13)
