# Спецификация фичи 012: диспетчер ДДС — как в памятке «Работа на АРМ-112»

**Ветка**: `feat/011-dds-sasha` (от `SASHA` `d0c9d2f`)
**Создана**: 2026-10-20
**Статус**: согласована с владельцем 2026-10-20, в реализации (задачи — `tasks.md`)
**Источник истины**: памятка «Работа на АРМ-112. Памятка для дежурно-диспетчерских служб» (ГБУ «Система 112», 2025),
билеты «Отработайте вызовы от заявителя», классификатор v046 — материалы кейса (`hack/Фронт/`, архив кейса команды 82).

## 1. Обзор

Сверка 20.10.2026 показала: каркас режима ДДС совпадает с памяткой (автостатус «Получена службой», 30 с, форма
«Статус · Номер наряда · Комментарий», порядок статусов, закрытие карточки, 7 типовых нарушений), но в трёх местах
тренажёр учит не тому, что делает диспетчер ДДС:

1. в карточке ДДС есть поля, которых нет в АРМ-112 ДДС (стр. 23): «Действие диспетчера», номер наряда в теле
   карточки, «Отработки», таймер в шапке; оценка штрафует за пустые «Действие диспетчера» / «Номер наряда»;
2. эталон ДДС требует звонков в 101/102/103/104 и перевода в ЦУС — это работа специалиста-112 (стр. 7–8, 15–16):
   службы оповещает система-112 по списку оповещения, а ДДС при изменении ситуации звонит на 112 (стр. 33);
3. «своя служба» в карточке — первая подходящая плитка списка оповещения, а не служба обучающегося: egorov
   («ДДС района Обручевский») ставит статус за «Мосгортранс». В АРМ-112 диспетчер работает в блоке своей службы
   («Упр. Чертаново Южное» на стр. 23–24).

## 2. Что делает диспетчер ДДС (памятка)

| Шаг | Страница |
|---|---|
| Карточка приходит, потому что служба есть в списке оповещения по ЕКП | 7–8 |
| Открытие = «Получена службой» (автоматически) | 22 |
| Читать всё, включая описание | 19 |
| В 30 с — «Принята» / «Не принята» (комментарий: причина и кому передано) карандашом в блоке своей службы | 22, 24 |
| Ход работ по факту информации: Начало реагирования → Прибытие → Проведение работ → Работы завершены / Отказ | 22, 25 |
| Все результаты — в комментарии к статусам; завершающий статус закрывает карточку | 22, 25 |
| Нужны другие службы — звонок на 112 | 33 |
| Доклад руководству своей службы по софтфону (точка C) | Q&A, раздел «точки A/B/C» |

## 3. Решения владельца (2026-10-20)

- **D1.** Звонки в 101–104 и перевод в ЦУС из эталона ДДС убираются.
- **D2.** Доклад точке C (301/302/303) — плюс к оценке, отсутствие не штрафуется; звонок на 112 ожидается только
  в сценариях, где ситуация меняется.
- **D3.** Оформляется новой фичей 012; 011 не переписывается.

## 4. Требования

- **FR-001** Карточка ДДС без «Действия диспетчера», номера наряда в теле карточки, «Отработок» и таймера в шапке.
  Текст и номер наряда вводятся только в форме статуса.
- **FR-002** Отсчёт нормативов (реакция 30 с, отработка 3 мин) — в полосе тренажёра, не в карточке (как спека 007, FR-002).
- **FR-003** Оценка ДДС: обязательные «действие диспетчера» и «номер наряда» закрываются комментарием к статусу и
  номером наряда из формы статуса; смысл и грамотность — по комментариям.
- **FR-004** Эталоны сценариев ДДС: без `call:101…104` и `transfer:*`; ключевые фразы — без действий других служб
  («бригада СМП направлена», «наряд полиции направлен», «вызов переведён в ЦУС…»).
- **FR-005** Доклад точке C в эталоне ДДС необязателен: нет звонка — нет ошибки.
- **FR-006** Софтфон не подсказывает «Ожидается по эталону».
- **FR-007** Своя служба = служба обучающегося по таблице «профиль → службы» (`PROFILE_MAPPING_SEED`, первая служба
  профиля, для ДДС района — управа); если в списке оповещения карточки её нет, она показывается в списке
  (карточку направили в эту службу). Статус ставится в её блоке; журнал показывает её статус.

## 5. Критерии приёмки

- **SC-001** Карточка ДДС у egorov совпадает по составу с карточкой стр. 23: нет полей «Действие диспетчера»,
  «Номер наряда» в теле, «Отработок», таймера; в полосе тренажёра видны норматив реакции и отработки.
- **SC-002** Отработка «Принята (с номером наряда и комментарием) → ход работ → Работы завершены» без звонков
  даёт оценку без замечаний «пропущен звонок», «не заполнено поле dispatcherAction / outfitNumber».
- **SC-003** У egorov карандаш — на блоке «Упр. Обручевский»; у petrova — на «Упр. Чертаново Южное».
- **SC-004** Софтфон не показывает «Ожидается по эталону».

## 6. Вне объёма

- Рабочее место специалиста-112 (фича 009, ветка SASHA, ведёт другая сессия).
- Подача ДДС только карточек, где его служба есть в списке оповещения ЕКП: отбор остаётся по профилю (спека 011);
  уточнение — отдельной задачей.
