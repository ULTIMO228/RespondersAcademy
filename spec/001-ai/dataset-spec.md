# Датасет дообучения: смысловой разбор (фича 001, US5)

Дополнение к [ai-workflow.md](ai-workflow.md), [data-model.md](data-model.md) `TrainingExample` и [contracts/semantic-review-v1.schema.json](contracts/semantic-review-v1.schema.json). Обучение Qwen3.5-0.8B (QLoRA) идёт **вне репозитория**, здесь данные готовятся, проверяются и упаковываются. Сети и загрузки моделей не требуется.

## 1. Что обучаем

Одна задача из [technical-context.md](technical-context.md): **смысловой разбор спорного случая** — сравнить текст курсанта с фактами утверждённого эталона и вернуть `SemanticReviewV1` с кратким проверяемым основанием. Время, адрес, код ЕКП, статусы и балл модель не оценивает (FR-023). Фабула вариаций для преподавателя и прочее в этот датасет не входят.

## 2. Формат примера

Чат-JSONL (`messages`: `system`, `user`, `assistant`), обучение по токенам `assistant`.

- `system` — `backend/ml/prompts/semantic_review_v1.md` дословно (sha256 в manifest).
- `user` — JSON: `mode`, `field`, `situation` (очищенная ситуация), `referenceFacts[{id,text}]`, `verifiedRules[{rule,result}]` (контекст, на метку не влияет), `studentText`.
- `assistant` — JSON по схеме: `decision`, `referenceFactIds`, `missingFactIds`, `explanation` (≤ 300 знаков), `confidence`.

| Поле `field` | Режим | Что сравнивается | Факты |
|---|---|---|---|
| `description` | operator112 | описание происшествия в карточке | 1–4 смысловые части фабулы |
| `dispatcherAction` | dds | действие диспетчера | «сообщение принято» + направленные службы из `expectedServices` |
| `serviceReport` | dds | доклад руководителю службы | адрес, суть, пострадавшие, номер карточки |
| `refusalComment` | dds | комментарий к «Не принята» | причина + кому передано (переводы в другой регион, дубли) |

## 3. Метки и правила

| `decision` | Условие | `missingFactIds` | `confidence` |
|---|---|---|---|
| `equivalent` | текст передаёт все факты, пусть иначе | `[]` | 0,80–0,95 |
| `different` | факт пропущен или искажён; либо описано другое происшествие | пропущенные/искажённые | 0,75–0,95 |
| `uncertain` | вердикт вынести нельзя | `[]` | 0 |

`referenceFactIds` — все переданные в запросе ID (пусто при пустом эталоне). Причины `uncertain`: `ambiguousText` (факты названы косвенно, два прочтения), `offTopic` (бессвязный или не по делу), `foreignFact` (факт эталона не относится к ситуации), `emptyReference` (эталон пуст). Скудный, но однозначный текст — это `different`.

Приёмы порождения (`recipe.perturbation`): `equivalent` — paraphrase, colloquial, abbreviated, verbose, typos; `different` — omitOne, omitMany, contradict, swapIncident; `uncertain` — перечисленные выше. Около 6 % примеров содержат инъекцию инструкции в тексте курсанта (метка определяется остальным текстом; в объяснении пометка «Посторонняя инструкция проигнорирована»).

## 4. Объём и разбиение

Цель — около 800 примеров: `decision` 40/40/20, поля 45/25/20/10 %. Билеты (32) делятся **до генерации** на train / validation / holdout (22 / 5 / 5); билеты, связанные `duplicateOf`, всегда в одном разбиении. Holdout закрыт: его пакеты генерируются последними, после заморозки состава, и не участвуют в обучении и подборе.

## 5. Данные и ПДн

Источник — 96 ситуаций `spec/000-фронт/mocks/cards.json` через реестр `sanitized_tickets.json` (gate `ml/source_gate.py`, `piiCheck=passed`, утверждает человек). ФИО пациентов, даты рождения (год сохраняется) и госномера в фабулах заменяются сгенерированными (`ml/dataset/identities.py`, детерминированно по карточке). Агент получает только очищенные значения; валидатор отклоняет любое ФИО, телефон, дату или госномер вне плана.

## 6. Конвейер

1. `ml.dataset.plan` — семена: истинные метки, факты, рецепт; пакеты по 25 случаев.
2. Агент Haiku по `AGENT_BRIEF.md` пишет `studentText` и `explanation`; метку и факты не меняет.
3. `ml.dataset.validate` — схема, объём, ПДн вне плана, потеря идентификаторов факта, рецепт инъекции и упоминания заявителя, служебные слова, дубли; мягкие флаги для разбора.
4. Смысловой разбор Claude по каждому примеру (`reviews/claude-review.jsonl`: `accept` / `reject`, при необходимости `fix`); отклонённые перегенерируются.
5. Выборка для человека (`reviews/human-sample.md`, ≈ 8 %, стратифицирована по вердикту, плюс инъекции).
6. `ml.dataset.pack` — принятые примеры → `release/{train,validation,holdout,metadata}.jsonl`, `system_prompt.md`, `manifest.json`, `DATASHEET.md`, zip в `backend/var/ai_dataset/`.

## 6а. Честные ограничения

- Судья той же модельной семьи, что и генератор: нарушается требование T042 о независимом подтверждении. Выпуск помечен `independentJudge: false` и подтверждён детерминированной проверкой, разбором Claude и выборкой человека.
- Записи `TrainingExample` из data-model.md с `baseOutput` и `teacherCandidate` здесь не заполняются: базовая модель на этом оборудовании не запускается. Поля метаданных (`labels`, `checks`, `split`, `sourceTicketId`) соответствуют модели.
- Тексты курсантов синтетические. Всего 32 исходных билета: метрики holdout показывают перенос на новые билеты, а не на новые типы происшествий.

## 7. Критерии приёмки датасета

| Критерий | Порог |
|---|---|
| Ответ `assistant` валиден по схеме | 100 % |
| Ссылки на факты только из запроса | 100 % |
| ПДн вне плана / реальных ПДн | 0 |
| Утечка билета между разбиениями | 0 |
| Точные дубликаты `studentText` | 0 |
| Баланс `decision` | 40/40/20 ± 3 п.п. в каждом разбиении |
| Смысловой разбор Claude | 100 % принятых примеров разобраны |
| Выборка человека | ≥ 8 % принятых, без отклонений либо отклонённые исключены |

## 8. Итоги выпуска v1 (2026-09-28)

- План — 783 случая (787 минус 4 случая с дублирующимися фактами эталона); принято **762**: train 531, validation 121, holdout 110; `equivalent` 301, `different` 309, `uncertain` 152 (в каждом разбиении 39–41 / 40–41 / 18–21 %). Инъекции — 47. Режимы: dds 409, operator112 353.
- Проходов генерации: 4 (первый — 787 случаев, дальше только отклонённые). Первый проход принят на 74 %, на «неоднозначных» текстах и «чужом происшествии» агент срывался стабильно, поэтому в валидатор добавлены правила (совпадение текста с фактами эталона, потеря названия региона, выдуманные сокращения, цифры в неопределённом тексте) и 42 неопределённых примера написаны Claude вручную (`author: claude` в `metadata.jsonl`).
- Состав и хеши файлов — `backend/data/ai_dataset/v1/release/manifest.json`; упаковка — `backend/var/ai_dataset/ai-semantic-review-v1.zip` (вне git).
- Открыто: просмотр человеком выборки из 67 примеров (`reviews/human-sample.md`); отклонённые записываются в `reviews/human-review.jsonl`, затем `python -m ml.dataset.pack` пересобирает выпуск.
