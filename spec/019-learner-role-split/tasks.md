## Implementation Strategy

- **MVP = Phase 1 + 2 + US1 (T001–T032)**: специализация + запрет чужой зоны на фронте и сервере. Показывает владельцу самое главное и разблокирует остальное.
- Затем **US3** (быстрый выигрыш — убрать функции 112 из ДДС), потом **US2** (достройка 112), далее **US4**, **US5**.
- Каждую историю закрывать целиком: тесты красные → зелёные → чекпойнт → отметка `[X]` только после реальной проверки; незавершённое оставлять открытым.
- Делегирование (из плана): бэкенд, миграции, гварды, моки — Haiku 5.5 xhigh; карточка ДДС и экран 112 (визуальный фронт) — Sonnet 5.5 medium; ревью безопасности гвардов — основная сессия; Opus — только для очень сложных задач (решение владельца 2026-10-20: ≈85% работы делает Haiku).

Карта, Сводка за день, База знаний; пара «112-обучающийся → ДДС-обучающийся» в цепочке; закрытие анонимных записывающих эндпоинтов (фича 008); реальная телефония; мобильная адаптация.
