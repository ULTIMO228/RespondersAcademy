# Контракт интерфейса: экран конструктора (фича 005)

Конструктор — часть платформы-обложки (кабинет преподавателя), не симулятора. Правила оформления — `docs/platform-design.md`, `spec/002-full-system-integration/07-platform-shell.md`, токены `--pf-*` и компоненты `src/shared/ui/platform`. Токены и компоненты симулятора (`/arm/*`) не используются, и наоборот (тест `src/app/layouts/simulatorBoundary.test.ts`).

## 1. Роуты и навигация

| Роут | Экран |
|---|---|
| `/teacher/constructor` | список сценариев-схем (FR-001) |
| `/teacher/constructor/[flowId]` | редактор черновика или просмотр версии (`?version=N`) |
| `/teacher/constructor/[flowId]/stats` | статистика (FR-050) |

- Пункт навигации преподавателя «Конструктор» (значок `doc`/`tasks`) — рядом с «Сценарии» в `PLATFORM_NAV.teacher`.
- `proxy.ts` уже закрывает `/teacher/:path*`, новые правила не нужны.
- Студенту экраны недоступны: серверный лэйаут отправит на `/forbidden`.

- Ширины: библиотека 320 px, свойства 380 px, нижняя панель 220 px (можно свернуть до заголовка); поле занимает остальное.
- Кнопка «Опубликовать ▾» при включённом согласовании называется «Отправить на согласование».
- Кнопки «Запустить тест» и «Опубликовать» недоступны, пока есть ошибки; подсказка объясняет почему.
- У эксперта и руководителя группы режим «только чтение»: библиотека скрыта, сверху «Согласовать», «Вернуть на доработку», «Сделать копию».

## 3. Вид блока

- Карточка на белом фоне (`--pf-bg-card`), поле — `--pf-bg-page`, рамка 1 px `--pf-border`, скругление по токену платформы. Все токены брать из `src/shared/ui/styles/tokens-platform.css`, не придумывать (урок L007).
- Слева цветная полоса группы:

  | Группа | Цвет |
  |---|---|
  | «Начало и конец» | нейтральный |
  | «Вызов и заявитель» | основной |
  | «Действия диспетчера» | акцентный |
  | «Логика» | вторичный |
  | «Обучение» | информационный |

  Конкретные токены выбираются в фазе 3 из `tokens-platform.css`, новые цвета — только туда.
- Строка 1: значок (`PfIcon`) + название типа («Действие»), 16 px полужирный.
- Строка 2: краткое содержание настроек («Оповестить службу 104 · 60 с · 2 балла»), 16 px; не больше двух строк, далее «…».
- Выходы — подписанные «таблетки» на правом крае («Да», «Нет», «Выполнено»); вход — точка на левом крае. Зона захвата не меньше 44 × 44 px.
- Состояния рамки:
  - выделен — толстая рамка основного цвета;
  - ошибка — красная рамка со значком ⛔;
  - предупреждение — жёлтая рамка со значком ⚠;
  - активен в тесте — пульсирующая рамка;
  - пройден в тесте — галочка.
- Стрелки — плавные кривые (как в Unreal) с подписью выхода у начала; выделенная стрелка удаляется клавишей Delete.

## 4. Управление

| Действие | Мышь | Клавиатура |
|---|---|---|
| Добавить блок | перетащить из библиотеки | выбрать в библиотеке, Enter — блок встаёт справа от выделенного и соединяется с его первым свободным выходом |
| Выделить | клик | Tab / Shift+Tab по блокам |
| Переместить | перетащить | стрелки (Shift — шаг 40 px) |
| Соединить | тянуть от выхода к блоку | в свойствах «Следующий шаг → [список блоков по названию]» |
| Удалить | кнопка в свойствах | Delete |
| Отменить / повторить | — | Ctrl+Z / Ctrl+Shift+Z (50 шагов) |
| Масштаб | Ctrl+колесо, кнопки | Ctrl+= / Ctrl+− / Ctrl+0 |
| Сохранить | кнопка | Ctrl+S |

## 5. Состояния экрана

Состояния по `AGENTS.md` §7: загрузка, пусто («Перетащите первый блок из библиотеки слева»), ошибка (с повтором), успех; «требуется сервер» без бэкенда; «Сценарий изменён другим пользователем» при 409.

## 6. Словарь интерфейса

Используем: «Сценарий», «Блок», «Следующий шаг», «Условие», «Действие», «Обязательный вопрос», «Вариант», «Проверить», «Опубликовать», «Черновик», «Версия», «Согласование».

Не используем (проверяется тестом SC-007): «переменная», «тип данных», «узел», «нода», «порт», «граф», «булево», «null», «JSON».
