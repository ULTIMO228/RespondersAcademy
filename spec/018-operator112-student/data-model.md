# Data Model: 018 — профиль режима обучаемого

## User (изменение)

| Поле (API / БД) | Тип | Обяз. | Правила |
|---|---|---|---|
| `trainingProfile` / `training_profile` | `"operator112" \| "dds"` | нет | Только для `role = student`; у teacher/admin всегда отсутствует. Отсутствие/`null` = «не задан» → доступны оба режима. |
| `service` | string | нет | Для профиля `operator112` в демо — «ЦОВ системы-112»; профиль службы ДДС (`PROFILE_MAPPING_SEED`) для такого курсанта не вычисляется. |

`to_public()` отдаёт `trainingProfile` только если задан (как `group`/`service`).

**Демо-данные**: `u-005` ivanov — `trainingProfile: "operator112"`, `service: "ЦОВ системы-112"`; логин, пароль, ФИО, АРМ 1, группа ДДС-01 без изменений. Остальные пользователи — без поля.

**Миграция `0006_user_training_profile`**: `ADD COLUMN training_profile VARCHAR(16) NULL`; data-шаг: `UPDATE users SET training_profile='operator112', service='ЦОВ системы-112' WHERE login='ivanov'`. Downgrade — drop column (служба не восстанавливается).

## Правило совместимости

```
allows(user, mode) =
    user.training_profile is None
 or user.training_profile == mode
```

`mode` — `trainingMode` задания / занятия (`dds` | `operator112`). Задания `chain` правилом не затрагиваются (они и так только для чтения).

| Где | Курсант несовместим → |
|---|---|
| Создание задания (`POST /api/v1/assignments`) | 400, в сообщении ФИО несовместимых |
| Создание занятия | 400, то же |
| Список заданий курсанта | задание скрыто |
| Карточка/запуск задания курсантом | 403 «Задание режима … недоступно для учётной записи …» |
| Список/вход в занятие курсантом | скрыто / 403 |
| Рекомендации курсанта | нет карточек, категорий и R10 для запрещённого режима |
| История/аналитика в кабинете курсанта | строки запрещённого режима не показываются |
| Отчёты, рейтинг, карта ошибок преподавателя | без изменений (FR-007) |

## AuditEvent (без новых типов)

Изменение профиля админом — часть существующей записи «изменение пользователя»: фрагмент `профиль «Не задан» → «Специалист системы-112»`.

Подписи значений: `operator112` — «Специалист системы-112», `dds` — «Диспетчер ДДС», нет — «Не задан».
