# Фича 005 — Сводная успеваемость для руководства (экран + Excel + PDF)

Статус: **согласовано владельцем 2026-10-19** (вопросы §7 решены рекомендуемыми значениями: «класс» = учебная группа, руководство = роль admin, экран + Excel + PDF, ФИО в файле есть). Подробности — `data-model.md`, `contracts/performance-endpoints.md`. Эндпоинты упрощены: один `GET /performance/report` вместо трёх срезов. **Реализовано T001–T005 (2026-10-19)**: экран `/teacher/performance` (teacher) и `/admin/performance` (admin), Excel и PDF; открыто T006 (демо-данные для школы, проверка руководителем).

## 1. Зачем

Руководству нужен один отчёт «как учатся»: по всей организации, по группам (классам) и по отдельным обучающимся, за выбранный период, который можно открыть на экране, распечатать и выгрузить в Excel. Сейчас такого нет (проверено по коду 2026-10-19): есть список обучающихся и профиль одного (`/teacher/students[/id]`), показатели одной группы (`/teacher/groups/[groupId]`), отчёт одного занятия (CSV/PDF/XLSX) и карта ошибок. Сводки «все группы вместе» и сравнения групп между собой нет.

## 2. Уровни и что в каждом

| Уровень | Вопрос руководителя | Содержимое |
|---|---|---|
| Все вместе | «Как учится организация?» | число обучающихся и групп, попыток, средний балл, доля уложившихся в норматив реакции (30 с) и отработки (3 мин), доля сдавших экзамены, динамика к прошлому периоду, топ-5 типов ошибок |
| Группа (класс) | «Какая группа сильнее, какая отстаёт?» | те же показатели по каждой группе в одной таблице, сортировка, отметка групп ниже порога; связь с картой ошибок группы |
| Обучающийся | «Кто в зоне риска?» | попытки, средний балл, нормативы, число экзаменов и сдач, рейтинг (если есть), главный проблемный этап |

Период: 2 недели / месяц / всё время / свой диапазон дат. Режим: ДДС, специалист-112, оба.

## 3. Выходные форматы

- **Экран** `/teacher/performance`: три вкладки (Все вместе, Группы, Обучающиеся), крупный шрифт и цели ≥ 44 px, как у карты ошибок; цвет не единственный носитель смысла.
- **Excel (.xlsx)**: листы «Сводка», «Группы», «Обучающиеся», «Ошибки», «Параметры» (период, режим, дата, кто сформировал); общий модуль `app/services/xlsx_export.py`.
- **PDF**: одна-две страницы «для директора»: ключевые числа, таблица групп, список зоны риска.
- Файлы открываются в Excel без ручной подготовки: шапка, фильтр, ширины, числа числами.

## 4. Права

teacher — только свои группы (`assigned_groups`); admin — все группы и сводка «организация целиком»; student — нет доступа. Отдельной роли «дирекция» нет (решение владельца, см. §7).

## 5. Данные и расчёт

Источник (нормативы — по умолчанию 30 с / 3 мин, не по сценарию, см. data-model): оценённые попытки (`Attempt` + `Evaluation`), итоговый балл — `effective_score` (с учётом правки преподавателя), нормативы — `_norms_for`, как в экспорте отчёта занятия. Новых таблиц не нужно; расчёт на чтении, одним запросом на период (без N+1). Пороги «зоны риска» и минимум попыток для вывода — настройки (по образцу `errorMap`).

## 6. Критерии приёмки

1. Показатели «все вместе» = сумма/среднее по группам (тест на эталонном наборе, посчитанном вручную).
2. Преподаватель не видит чужие группы ни на экране, ни в Excel/PDF; парные тесты 200/403/401.
3. Excel открывается, листы и числа совпадают с экраном (тест чтения файла).
4. Малое число попыток не даёт ложных средних: «мало данных» вместо числа.
5. Отчёт за 20 групп × 30 обучающихся строится ≤ 3 с на демо-данных.
6. Проверка директором/руководителем: понятно без объяснений за ≤ 1 мин (как SC-001 в 003).

## 7. Вопросы владельцу

1. «Класс» = учебная группа (`User.group`)? Есть ли второй уровень выше группы (например, «школа/филиал»)?
2. Кто руководство: достаточно роли admin, или нужна отдельная роль «руководитель» с доступом только на чтение?
3. Какие показатели обязательны для директора (балл, нормативы, сдача экзаменов, посещаемость/число занятий)? Нужны ли оценки словами («хорошо/удовлетворительно»)?
4. Нужен ли PDF сразу или достаточно Excel + печать с экрана?
5. Нужны ли фамилии обучающихся в файле для руководства (персональные данные в выгрузке) или допускается вариант без ФИО по группам?
