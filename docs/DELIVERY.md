→ «ТЗ §13–14, §18. Артефакты сдачи».

Статусы: **Готово** — артефакт существует и проверен; **Готово частично** — часть требования закрыта,
недостающее названо явно; **Не выполнено** — артефакта нет, указано что нужно сделать;
**Внешний трек** — вне репозитория фронта, владелец и статус указаны.

### Как закрыть строку 5 (скринкаст)

1. Прочитать [`demo-recording-plan.md`](demo-recording-plan.md) — там стенд, два окна браузера,
   параметры записи, данные дубля (`s-032`, `c-095`, номер 301) и 5 сцен с репликами.
2. Поднять свежую production-сборку (`npm run build && npm start`) — мок-стор в памяти, иначе в кадре
   будет состояние от репетиций.
3. Записать одним дублем, целевая длительность 4:40, предел 5:00.
4. Проверить `ffprobe` (длительность ≤ 300 с, есть аудиодорожка), заполнить раздел «Приёмка записи».
5. Положить файл как `docs/demo.mp4`, обновить эту строку и статус в [`COMPLIANCE.md`](COMPLIANCE.md),
   отметить `T5.3-04` в `spec/000-фронт/12-tasks.md`.

```bash

git ls-files | grep -E 'node_modules|\.env|\.next/' || echo "чисто"
grep -rniE '(api[_-]?key|secret|token\s*=)' src app scripts --include='*.ts' --include='*.tsx' --include='*.sh'
grep -rnoE 'https?://[a-zA-Z0-9._/-]+' src app public --include='*.ts' --include='*.tsx' --include='*.css'

```
