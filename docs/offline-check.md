## Устранённые внешние обращения

- **Телеметрия Next.js.** `next build` по умолчанию отправляет анонимную телеметрию на `telemetry.nextjs.org`
  (`npx next telemetry status` показывал «enabled»). Устранено в репозитории: скрипты `dev` и `build` в
  `package.json` выполняются с `NEXT_TELEMETRY_DISABLED=1`. Дополнительно на машине показа можно выполнить
  один раз `npx next telemetry disable`.

## Ограничения проверки (что осталось непроверенным)

- Проверка выполнена **на рабочей машине разработки с симуляцией офлайна** (весь исходящий HTTP/HTTPS
  заведён на «мёртвый» прокси `127.0.0.1:9`), а не на физически новой машине с выдернутым кабелем.
  Сборка, запуск, 11 экранов и демо-путь в этих условиях проходят полностью.
- `npm ci` на чистом профиле не выполнялся: команда удаляет `node_modules`, а репозиторием одновременно
  пользуются другие процессы сборки. Установка зависимостей — единственный шаг, требующий сети; для
  офлайн-машины нужен заранее скопированный `node_modules` (или локальный registry) и каталог браузеров
  Playwright.
- Браузеры Playwright (~1,1 ГБ) скачиваются с `cdn.playwright.dev` — это **dev-инструмент**, в прод-сборку
  (`.next`, `public`) он не попадает и на работу тренажёра офлайн не влияет.

## Как воспроизвести проверку

```bash
npm ci                                   # нужна сеть (единственный раз)
npx playwright install chromium          # нужна сеть (только для e2e)

# дальше сеть не нужна — проверяем это «мёртвым» прокси
export HTTP_PROXY=http://127.0.0.1:9 HTTPS_PROXY=http://127.0.0.1:9 ALL_PROXY=http://127.0.0.1:9
npm run build
npx next start -p 3140 &
E2E_REUSE_SERVER=true npx playwright test   # 16 тестов: smoke 11 экранов + демо-путь
```
