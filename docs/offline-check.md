## 3. Устранённые внешние вызовы

1. **Телеметрия Next.js**: `NEXT_TELEMETRY_DISABLED=1` прописана в скриптах `dev`, `build`, а также в `demo_up.sh` и `run_frontend_e2e.sh`.
2. **Скачивание весов моделей**: скрипт подготовки моделей `backend/ml/scripts/prepare_models.py` вынесен в отдельный предварительный этап и **не включён** в автоматический скрипт демо-стенда `./scripts/demo-up.sh`. Стенд стабильно функционирует на детерминированных правилах и лексических анализаторах при пустом `models/`.
3. **Cookie и авторизация**: авторизация выполняется полностью локально (генерация и проверка HS256 токена сервером с использованием локального `JWT_SECRET`).

## 4. Как воспроизвести полную офлайн-проверку

```bash
# 1. Запуск без исходящего интернета (симуляция через мёртвый прокси)
export HTTP_PROXY=http://127.0.0.1:9 HTTPS_PROXY=http://127.0.0.1:9 ALL_PROXY=http://127.0.0.1:9

# 2. Проверка валидатора данных и тестов фронтенда
npm run mocks:validate
npm run test

# 3. Проверка тестов бэкенда
cd backend && uv run pytest -q && uv run ruff check . && cd ..

# 4. Проверка холодного старта стенда
./scripts/demo-up.sh --skip-build
```
