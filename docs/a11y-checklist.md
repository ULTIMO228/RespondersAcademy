## Известные отступления (осознанные, не дефекты сборки)

1. **Палитра не меняется** — 32 из 80 замеренных пар ниже порога AA. Причина и компенсация по каждой
   группе — в `a11y-contrast.md`. Правка потребовала бы перекраски, прямо запрещённой HARD-правилом №1.
2. **Выделение «моей службы» на панели служб** — плитка подсвечивается кликом по свободной области
   (`ServicePanel.tsx`, `panel__slot`), с клавиатуры подсветку не включить. Подсветка декоративная:
   функциональные действия («История службы», «Сменить статус») — обычные кнопки и доступны с
   клавиатуры. Обёртывать плитку в кнопку нельзя — внутри уже есть кнопки (вложенные интерактивы).
3. **Часть иконочных кнопок без `title`** (свернуть список, пагинация ленты и аудита, шеврон дерева
   признаков, стрелки порядка сценариев): `aria-label` есть — скринридер называет их правильно,
   всплывающей подсказки для мыши нет. Референс ПОВ-112 подсказок в этих местах тоже не показывает.
4. **Кнопка «Закладка» в строке ленты** (`IncidentRowTools.tsx`) имеет имя и попадает в Tab-порядок,
   но обработчика не имеет — заглушка из волны 2. Это дефект поведения, а не доступности; правка
   вне зоны фазы 5.2.

## Что проверить в браузере (координатору)

Проверки ниже нельзя закрыть тестами — нужен реальный рендер:

1. **Tab-проход** `/login` → `/arm` → `/arm/card/c-095`: кольцо видно на каждом интерактиве,
   на тёмной ленте и на панели служб — белая подложка кольца читается, плотность таблицы не «поехала».
2. **Esc** закрывает попап истории, форму смены статуса, модалки; фокус возвращается на кнопку,
   с которой окно открыли.
3. **DevTools → Rendering → Emulate `prefers-reduced-motion: reduce`**: новая карточка не мигает,
   статичный маркер строки на месте, звуковой сигнал сохранён; без эмуляции мигание прежнее.
4. **Длинные данные на 1920px**: таблица держит 10+ строк без скролла; длинный адрес и тип
   обрезаются многоточием с подсказкой; плитки мониторинга и попап истории не разъезжаются.
5. **Вкладки браузера**: заголовок различается по экранам («Поиск происшествий — Учебный АРМ-112»).
6. **Визуальная сверка** `/arm` и `/arm/card/c-095` с `images/p12_Image66.png` и `images/p23_Image108.png`:
   правки фазы не должны были изменить ни одного цвета, поля или порядка блоков.
