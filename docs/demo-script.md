# Шпаргалка докладчика: демо-путь защиты (≤ 5 минут)

Актуализировано под Фичу 002 («Сквозная интеграция двух режимов и платформа-обложка»).
Соответствие конституции проекта (принцип IV): запуск одной командой без ручной подготовки, хронометраж ≤ 5 минут, честные ограничения.
Автоматический аналог пути — Playwright e2e (`e2e/two-mode-full-path.spec.ts`, `e2e/platform.spec.ts`).

---

## 1. Подготовка стенда (до выхода к экрану)

1. Запуск демо-стенда одной командой из корня:
   ```bash
   ./scripts/demo-up.sh
   ```
   Стенд автоматически очищает БД, применяет сиды и фикстуру сквозной цепочки A → B (T031), собирает фронт с `BACKEND_URL` и поднимает сервисы:
   - Фронтенд: `http://localhost:3130`
   - Бэкенд: `http://localhost:8130` (OpenAPI: `http://localhost:8130/api/docs`)
   *Время холодного старта: ~11 секунд.*

2. Два окна браузера (или приватное окно для курсанта):
   - Окно 1 (слева, 1280×800 или 1920×1080): Обучающийся `ivanov` / `student112`
   - Окно 2 (справа или переключение вкладки): Преподаватель `morozova` / `teacher112`, Администратор `admin` / `admin112`
   *Примечание: вход осуществляется по логину и паролю, номер АРМ необязателен, 2FA не используется (решение A14).*

## 3. Контрольные точки самопроверки хронометража

- Отметка **1:00** — курсант должен уже вести диалог на рабочем месте 112.
- Отметка **2:00** — завершён разбор карточки 112, переход к цепочке A → B.
- Отметка **3:00** — показан этап ДДС с сообщениями служб, переход к аналитике.
- Отметка **4:00** — показан кабинет преподавателя, переход к администратору.
- Отметка **4:40** — завершение демонстрации (запас до лимита: 20 секунд).

## 4. Запасные сценарии при непредвиденных сбоях

1. **Микрофон недоступен / нет модели Vosk**: голосовой доклад выводит сообщение «Распознавание речи недоступно», при этом карточка ДДС не блокируется и может быть завершена вручную через стандартный статус «Работы завершены».
2. **Модель Silero TTS не установлена**: входящий звонок заявителя показывает текстовый транскрипт с пометкой «Аварийный режим» — сценарий продолжается без звука.
3. **Случайное закрытие браузера**: при повторном открытии сессия сохраняется (HttpOnly cookie), незавершённая попытка восстанавливается с сервера.
