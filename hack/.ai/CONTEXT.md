## Обзор задачи
Хакатон «Лидеры цифровой трансформации», задача №9: «Учебный программный
симулятор подготовки операторов/диспетчеров экстренных служб по вызовам от
системы 112 с использованием ИИ». Заказчик — Департамент ГОЧСиПБ г. Москвы.

## Продукт (из заметок команды, оцифровано 21.09.2026)
Одна платформа = портал команды + учебный симулятор:
1. **Портал** — отдельные страницы: аналитика, история, советы, справочник,
   Я.Карта (справочник адресов Москва+МО), рекомендательная система,
   детекция каскадных ошибок («эффект домино»), генерация сценариев + контроль.
2. **Симулятор АРМ-112** — точная копия рабочего места ГБУ «Система 112»
   (вход по кнопке «Начать учёбу» с портала).

## Роли
- **Админ**: аккаунты/роли, мониторинг, безопасность, выбор ИИ-моделей (масштабирование).
- **Преподаватель**: аналитика, выбор/создание билетов (в т.ч. с ИИ), просмотр
  сложных ситуаций, заметки на карточке.
- **Обучаемый**, две подроли:
  - Оператор 112 (точка A): заполнение карточки (адрес, заявитель, описание,
    тип + опросная карта, набор служб).
  - Диспетчер ДДС (точка B): валидация карточки, статусы, звонки руководителям
    служб (точка C) по внутренней IP-телефонии.

## Ключевые решения
| Решение | Содержание | Источник |
|---------|-----------|----------|
| Аудио | записи диалогов, предварительно озвученные ИИ; в рантайме только проигрывание | команда (TTS на CPU с нужной скоростью невозможен) |
| «Только B→C» | относится к телефонии, не ко всему процессу; две подроли обучаемого сохраняются | постановщик (Str1fe, 18.09.2026) |
| Карта | локальный справочник адресов, география Москва + МО | команда |
| «Единая проблема» | вычеркнуто | автор заметок |
| Эффект домино | каскадные ошибки: система должна понимать, когда ошибки есть | автор заметок |
| Страницы vs встройки | модули платформы — отдельные страницы; вход в АРМ — кнопка «Начать учёбу» | автор заметок |
