# AGENTS.md — правила для агентов (RespondersAcademy / hack)

## READ при старте (в этом порядке)
1. `.ai/PROJECT_MAP.md` — карта проекта и статус
2. `.ai/CONTEXT.md` — текущий контекст задачи
3. `.ai/LESSONS.md` — ошибки, которые нельзя повторять
4. Нормативные источники под задачу:
   - UI/фронт → `Фронт/ФРОНТ-АРМ-112-ЕДИНЫЙ-ДОКУМЕНТ.md` + `Фронт/ПРАВИЛА-КОДА-ФРОНТ.md`
   - Данные/моки → `Фронт/МОКИ-ДАННЫЕ.md`
   - Продукт → `.foryou/Фичи/*.md`

## WRITE при завершении
1. `.ai/SESSION_STATE.md` — новый блок `## Now @YYYY-MM-DD` сверху: что сделано,
   найденное выполнением (`found_by_execution`), проверки, next_action
2. `.ai/LESSONS.md` — если допущена/найдена ошибка, которую нельзя повторять
3. `.foryou/CHANGELOG.md` — если изменение видно пользователю проекта

## Жёсткие правила
- Код фронта — только по FSD (`Фронт/ПРАВИЛА-КОДА-ФРОНТ.md`), Steiger-линтер зелёный
- Нормативные данные не дублировать — ссылаться на `Фронт/МОКИ-ДАННЫЕ.md` / единый документ
- Классификатор: только v.046_24
- Контур прототипа — локальный, без интернета; ИИ — CPU-only
- Аудио: никакого TTS в рантайме
- Не переносить файлы, не менять структуру `.ai/`/`.foryou/` без запроса владельца
- macOS FS case-insensitive: проверять `ls` после переименований (LESSONS L002)
