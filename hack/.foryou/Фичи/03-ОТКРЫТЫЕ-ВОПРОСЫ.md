## Итоговые решения (21.09.2026)

### 1. Способ работы с записями разговоров — РЕШЕНО

Диалоги **предварительно озвучиваются ИИ** и в систему закидываются готовые
записи. В рантайме только проигрывание — проблема скорости TTS на CPU снимается
(синтез выполняется один раз на этапе подготовки контента, не в реальном времени).
Подробнее — [01-ФИЧИ-ПЛАТФОРМЫ](01-ФИЧИ-ПЛАТФОРМЫ.md), раздел «Аудиоконтур».

### 2. Реализация модулей платформы — РЕШЕНО

Архитектура: **общая платформа** (портал) со всеми нашими отдельными страницами
(аналитика, история, советы, справочник и т.д.) и отдельной **кнопкой «Начать
учёбу»** — по ней происходит переход в систему АРМ (симулятор обучения).
Подробнее — [00-ОБЩАЯ-КОНЦЕПЦИЯ](00-ОБЩАЯ-КОНЦЕПЦИЯ.md), раздел 1.

### 3. Я. Карта в локальном контуре — РЕШЕНО

Справочник адресов с географией **только Москва и Московская область**
(покрывает весь датасет 96 билетов). Подробнее —
[01-ФИЧИ-ПЛАТФОРМЫ](01-ФИЧИ-ПЛАТФОРМЫ.md), фича 5.

### 4. Формат документации — РЕШЕНО

Текущий формат подтверждён: `Фичи/` — концепция продукта команды;
нормативные данные — в [МОКИ-ДАННЫЕ](../../Фронт/МОКИ-ДАННЫЕ.md) и
[ФРОНТ-АРМ-112-ЕДИНЫЙ-ДОКУМЕНТ](../../Фронт/ФРОНТ-АРМ-112-ЕДИНЫЙ-ДОКУМЕНТ.md);
документы ссылаются друг на друга.

### Закрытые вопросы по расшифровке заметок (для истории)

| Вопрос | Ответ автора заметок |
|--------|----------------------|
| «Единая проблема» (лист 1, п. 6) | Вычеркнуть, не включаем |
| Две колонки обучающихся | Две подроли обучаемого: Оператор 112 и Диспетчер ДДС; «только B→C» в Q&A — про телефонию, не про весь процесс |
| «Аудио-генерация (запись)» | TTS на CPU невозможен с нужной скоростью — только записи разговоров |
| «Есть ли аудио? Какое?» | Закрыто: записи разговоров, озвученные ИИ заранее |
| «Этап 2 … реп. экзам» | «Пред экзамена» — подготовка к экзамену |
| «Эффект … (оценка 1/2)» | Эффект домино — ошибки накладываются, нужно понимать, когда они есть |
| «Выбор моделей (все от ИИ)» | Возможность масштабирования |
| Я. Карта без интернета | Справочник адресов, география Москва + МО |
| Отдельные страницы или встройки | Общая платформа + кнопка «Начать учёбу» → АРМ |
