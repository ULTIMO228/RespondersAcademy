# Внешние ссылки и решения

## Аналог: medkit-app

- Репозиторий: https://github.com/bedriyan/medkit-app · Демо: https://medkit-app.vercel.app/
- Победитель хакатона Anthropic (апрель 2026). Голосовой симулятор пациента для врачей: реальный голосовой диалог с ИИ-пациентом, «старший врач» на Claude Opus ставит оценку по рубрике со ссылками на клинические гайдлайны.
- **За основу брать нельзя:** лицензия «Private — hackathon submission. Not licensed for redistribution»; весь стек облачный (Deepgram STT → Claude Haiku → Cartesia TTS, LiveKit Cloud, Vercel) — противоречит изолированному контуру; нет БД, ролей, генерации сценариев, отчётности.
- **Что взять идейно:** персона собеседника как данные (профиль + факты), из которых собирается промпт; оценщик с рубрикой по доменам и привязкой каждого замечания к источнику (у нас — пункты памятки вместо NICE/AHA); разделение «сценарий» (эталон) / «сессия» (действия + тайминги); формат демо «звонок → карточка → разбор».

## Речь

- **Яндекс SpeechKit (облако):** нельзя — ходит на серверы Яндекса. **SpeechKit Hybrid** (on-premise по договору) — для хакатона недоступен, но в документации указать как production-вариант через заменяемый провайдер.
- **Vosk** — офлайн STT, русский, потоковый, CPU. Поддерживает подмешивание доменной лексики (улицы, службы).
- **Silero TTS** — офлайн, русский, CPU, несколько голосов (муж/жен).
- **faster-whisper** (small) — лучше по качеству, но на CPU в реальном времени тяжелее.
- Рекомендация: слой `SpeechProvider` с реализациями Vosk+Silero (основная) и SpeechKit (адаптер, выключен) — закрывает критерий «интегрируемость».

## LLM

- Локально через **Ollama** / llama.cpp: Qwen, Llama, Mistral, Vikhr/T-lite, квантованные 7–14B. На типовом офисном ПК без GPU — медленно (единицы токенов/с); задачи ИИ-инженера: генерация вариаций сценариев (офлайн, не в реальном времени) и короткий ответчик.
- Облако допустимо только в процессе разработки (Q&A), итоговый прототип — локально.

## Эмбеддинги и NLP (ML)

- `intfloat/multilingual-e5-small` / `-base` — универсальные, хорошие на русском.
- `deepvk/USER-base` — одна из лучших на русском (ruMTEB).
- `cointegrated/rubert-tiny2` — 120 МБ, для реального времени и дообучения на CPU.
- `ai-forever/sbert_large_nlu_ru` — чисто русская, тяжёлая.
- `sentence-transformers`, `scikit-learn`, `rapidfuzz`, LanguageTool (офлайн-сервер на Java).

- ПП Москвы № 1420-ПП от 01.09.2020 — положение о системе-112 в Москве (+ 2852-ПП от 13.12.2022).
- ПП РФ № 2071 от 27.11.2021 — правила взаимодействия сил и средств.
- Приказ МЧС № 192 от 14.03.2022 — форма 3/112.
