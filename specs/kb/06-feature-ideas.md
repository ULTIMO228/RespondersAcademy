# Идеи сверх ТЗ

Сгруппированы по адресату. ★ — попадает в ML-зону. Актуализировано после Q&A (обучаемый — диспетчер ДДС, диалога с заявителем нет).

## Для жюри-преподавателей (максимальный эффект на питче)

- **Табло класса на внешний монитор** — в кратком описании кейса есть «вывод на внешний монитор». Отдельный экран без управления: кто из учеников на каком статусе, таймеры, кто уложился в норматив, красные карточки «Не оповещено».
- **Разбор карточки «как в спорте»** ★ — после отработки ученик видит таймлайн своих действий с подсветкой: зелёное — верный статус вовремя, красное — пропущено/поздно/неверно, с ссылкой на пункт памятки. Плюс транскрипт доклада с отметками, что назвал, что нет.
- **Импорт билетов преподавателя** (docx/xlsx) → система превращает их в сценарии. Прямо «загрузка материалов в базу» из ТЗ.
- **Сертификат по итогам аттестации** в PDF — упомянут в форматах ТЗ. Дёшево, выглядит законченно.
- **События по кнопке преподавателя** — во время занятия кинуть ученику повторный звонок по тому же адресу (дубль), карточку от ВИС с неполными данными, звонок «из отдела контроля» с вопросом. Реализует «управление ситуацией с рабочего места преподавателя».

## Реалистичность потока карточек

- **Типы карточек по источнику:** от оператора 112 (полная), от ВИС (без признаков, пострадавшие только в описании), дубль, ЭРА-ГЛОНАСС.
- **Ловушки из билетов:** адрес вне Москвы, неполный адрес, «03 не требуется», непрофильное происшествие, несколько служб.
- **Нагрузка:** настраиваемый темп поступления карточек, всплески.
- **Голоса ответчика:** мужской/женский, разные по службе (Q&A прямо просит вариативность).
- **Бонус на перспективу:** ИИ-заявитель с голосом — заказчик сказал, что оценит как сильное преимущество, но в MVP не требует.

## Оценка и аналитика ★

- **Профиль компетенций** — радар: скорость первичного статуса, полнота цикла, правильность решений, качество комментариев, грамотность. Динамика по занятиям.
- **Тепловая карта группы**: группа ЕКП × тип ошибки (7 категорий нарушений из памятки).
- **Адаптивная сложность** — рейтинг ученика/сценария, подбор следующего. Это «прогнозирование» из критериев.
- **Прогноз готовности к аттестации** — «при текущей динамике выйдет на норматив через N занятий».
- **Детекция угадывания** — статус проставлен быстрее, чем можно было прочитать карточку.
- **Сравнение с «золотым» диспетчером** — эталонная траектория действий vs. траектория ученика.
- **Проверка адресов со справочником** — предупреждение «похожая улица: Дубининская» прямо в поле ввода.

## Для ученика

- **Режим подсказок** на низкой сложности: подсветка следующего ожидаемого статуса, незаполненного обязательного комментария.
- **Прослушать свой доклад** — запись WAV с отметками.
- **Горячие клавиши** как в реальном АРМ-112 (если найдём в документации).

## Что выбрать при нехватке времени

1. Разбор карточки с подсветкой ★ — самая понятная демонстрация ИИ-оценки.
2. Тепловая карта + радар ★ — закрывает «наглядность диаграмм».
3. Табло класса — дёшево, в духе кейса.
4. События по кнопке преподавателя — «управление ситуацией».
5. Адаптивная сложность ★ — прямой ответ на критерий «прогнозирование».
