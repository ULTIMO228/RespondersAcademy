## Что нужно фронтендерам для подключения Phase 10

1. OpenAPI живого сервера: `http://localhost:8000/api/docs` (TS-типы — `npm run api:types`, задача фронтендеров по плану).
2. Контракт: `contracts/v1-endpoints.md` (таблицы «Билеты и аудио», «Режим специалиста-112» — уточнены по реализации).
3. Последовательность вызовов и демо-данные: `quickstart.md` §7. Демо-задания из сида: `asg-001` (тренировка, билеты c-010 и c-050, подсказки при простое 20 с) и `asg-002` (экзамен, c-071 и c-090, порог 70, одно прослушивание, без подсказок) для `ivanov` / `petrova`.
4. Особенности, о которых стоит знать:
   - все `/api/v1/*` требуют сессию (401); cookie `arm112_session` фронта подходит как есть;
   - `POST /operator112/attempts` в тренировке возвращает открытую попытку повторно (200), в экзамене повтор по билету → 409;
   - `hints { enabled, idleSec, steps[] }` приходят в попытке — таймер простоя считает фронт и шлёт событие `hintShown` (FR-017);
   - аудио: `attempt.audio.status` = `pending | ready | failed`; при `failed`/`emergency: true` показывать `transcript` с пометкой «аварийный режим» (FR-013); файл — `GET /tickets/{id}/audio/file` (WAV; в экзамене второй запрос → 409);
   - `notification-list` — по событиям `signSelected`/`fieldChanged`; `conditional[]` — службы с невыполненным условием, их можно добавить вручную (`serviceAdded`), удалять нельзя;
   - `submit` принимает `CardDraft` (форма в контракте); минимум — адресный блок и описание/опросная карта; ответ содержит новую карточку `incident_cards` и `evaluationId`.
5. Эталон API — `backend/tests/contract/test_v1_operator112.py`: там весь цикл в виде запросов/ответов.

## Как поднять локально

```bash
cd backend && uv sync --extra nlp --extra pg --group dev
uv run python -m ml.scripts.prepare_models            # rubert-tiny2; --only tts — Silero для аудио режима 112
uv run python -m ml.scripts.train_classifier          # артефакт классификатора (вне git)
uv run python -m app.seed.load --reset                # схема + сиды (после Phase 10 схема изменилась)
uv run uvicorn app.main:app --port 8000               # http://localhost:8000/api/docs
```

Фронт с реальным бэкендом: `BACKEND_URL=http://localhost:8000 npm run dev` (в `.env.local` уже задано). Гейт волны A целиком: `backend/scripts/run_frontend_e2e.sh`. Полная инструкция — `quickstart.md`, детали бэкенда — `backend/README.md`.
