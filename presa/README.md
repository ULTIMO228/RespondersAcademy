# Презентация для защиты (команда MISIS&MR.DRUN)

Презентация собрана по шаблону хакатона «Лидеры цифровой трансформации 2026»: 11 слайдов, заметки докладчика внутри.

## Что здесь лежит

| Путь | Что это |
|---|---|
| `Responders_Academy_MISIS-MR.DRUN.pptx` | готовая презентация |
| `Responders_Academy_MISIS-MR.DRUN_preview.pdf` | превью, отрисованное LibreOffice (в PowerPoint переносы строк могут немного отличаться) |
| `assets/template_base.pptx` | шаблон хакатона + копия слайда 27 (второй демо-слайд) в конце, база для сборки |
| `assets/gochs_logo.png` | логотип Департамента ГОЧСиПБ со слайда 6 шаблона |
| `assets/photos/original/` | исходные фото участников (1 Алексеев, 2 Хасянов, 3 Янеев, 4 Яров, 5 Ткаченко) |
| `assets/photos/photo1–5.jpg` | фото, обрезанные под рамки слайда «Команда» |
| `scripts/make.py` | скрипт сборки: весь текст слайдов, заметки, фото, порядок слайдов |
| `scripts/crop_photos.py` | обрезка фото |

## Как пересобрать

Нужны Python 3, `python-pptx`, `lxml`, `Pillow`.

```bash
python3 presa/scripts/crop_photos.py   # только если поменяли фото или кадрирование
python3 presa/scripts/make.py          # перезаписывает presa/Responders_Academy_MISIS-MR.DRUN.pptx
```

Скрипт перезаписывает готовый файл. Правки, сделанные руками в PowerPoint, при пересборке пропадут: либо правьте текст в `make.py`, либо дальше работайте только в PowerPoint.

Порядок слайдов шаблона в сборке: 7, 8, 9, 10, 11, 24, 25, 27, копия 27, 16, 17.
