## Ключевые факты

1. **Нормативы боевой Москвы**: опрос заявителя — 1 минута, отправка карточки — 30 секунд (совпадает с дефолтным таймером из ТЗ хакатона).
2. **Структура данных**: обращение (УЧОЛ — заявитель) → карточка происшествия (УКИО) → назначение ДДС → бригады → результат реагирования. Поля задокументированы в FIELDS.md (~130 полей, включая поимённую спецификацию от второго вендора protei).
3. **Классификатор**: московский не публикуется; берём типовой (Камчатский край + УСПО-112 МЧС), структура «Вид (служба) → Тип происшествия» — см. CLASSIFIER.md.
4. **Айдентики у заказчика нет в открытом доступе** → дизайн-тема в духе mos.ru (см. BRAND-AND-SOURCES.md).
5. **Идентификаторы карточек** выглядят как `май26_ДТП_008` (месяц_тип_номер) — мелочь, а на демо добавляет реализма.
