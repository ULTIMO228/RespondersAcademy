# Интерфейс АРМ-112 — структура

Составлено по текстовым дампам руководств:

- **iskratechno-2024.txt** — «Приложение Оператора Системы-112. Руководство пользователя», АО «Искра Технологии», март 2024, 85 стр. (основной источник);
- **iskrauraltel-2016.txt** — «Руководство оператора АРМ 112», IskraUralTEL, август 2016, код KSS7085B0-EDR-030;
- **arm-edds.txt** — тот же документ, что iskrauraltel-2016 (тот же код KSS7085B0-EDR-030, текст совпадает), поэтому ссылки даются как «iskrauraltel-2016»;
- **protei-2024.txt** — «СПО-112. Руководство оператора системы-112», СПб, 2024, 133 стр. (другой вендор; вынесен в отдельный раздел 13).

УКИО = унифицированная карточка информационного обмена (карточка происшествия). УЧОЛ = унифицированная часть опросного листа (карточка обращения). ДДС = дежурно-диспетчерская служба. МО = муниципальное образование (район).

---

## 1. Состав главного окна

Интерфейс АРМ оператора Системы-112 состоит из пяти основных частей (iskratechno-2024, стр. 14):

1. **Информационная панель** — сведения об операторе, количестве текущих вызовов и SMS, состояние АРМ, текущие дата и время.
2. **Панель функциональных кнопок** — функциональные кнопки (карта, база знаний, сводка, быстрый доступ).
3. **Панель работы с обращением** — информация о текущем обращении и команды управления им; в режиме редактирования обращения в этой области отображается панель УЧОЛ.
4. **Список карточек** — список всех карточек происшествий, зарегистрированных в Системе-112; при открытии карточки в этой области вместо списка отображается открытая карточка.
5. **Панель вкладок** — функциональные вкладки для разных сценариев работы.

В iskrauraltel-2016 (стр. 33) состав главного окна описан иначе (более старая версия): список карточек происшествий; панель работы с обращением; область «Общие сведения» (оператор, ДДС, МО, очередь, карточки в состоянии «Новая»); панель «Приём обращений»; «Состояние рабочего места»; кнопки «История обращений», «Карта», «Сводка»; кнопки быстрого вызова ДДС; панель управления телефонными вызовами.

## 2. Информационная панель

Состав (iskratechno-2024, стр. 14–17):

| Элемент | Что показывает |
|---|---|
| Оператор | Имя пользователя, работающего с АРМ |
| ДДС | Тип оператора в Системе-112 и группа, к которой он принадлежит |
| МО | Один из МО, обслуживаемых ДДС оператора; щелчок по заголовку открывает подробный список МО |
| Требуют реакции | Количество карточек, требующих реакции оператора |
| Очереди → Вызовы | Количество вызовов в очереди ДДС оператора; при наведении — всплывающее окно с очередью вызовов |
| Очереди → SMS | Количество SMS в очереди; при наведении — всплывающее окно с единой очередью SMS и пропущенных вызовов |
| Пропущенные | Количество вызовов, завершенных до появления у оператора окна принятия вызова; нажатие открывает вкладку СПИСОК ОБРАЩЕНИЙ с фильтром по пропущенным |
| Прием обращений | Переключатель с индикатором режима приема обращений (см. 2.1) |
| Состояние | Индикатор работоспособности АРМ (см. 2.2) |

### 2.1 Переключатель «Прием обращений» — цветовая кодировка

- зелёный — готовность и возможность принимать обращения;
- красный — прием обращений выключен оператором вручную;
- жёлтый цвет текста — невозможность принимать обращения по техническим причинам;
- серый (тёмно-серый) — прием выключен автоматически / логически невозможен (например, уже есть обращение)

(iskratechno-2024, стр. 16 и 70; iskrauraltel-2016, стр. 15). Во время разговора приём других вызовов невозможен: вызовы переадресуются свободным операторам или попадают в очередь (iskratechno-2024, стр. 70).

### 2.2 Индикатор «Состояние» (работоспособность АРМ)

- зеленый шарик с белой галочкой — нет проблем со связью АРМ с ключевыми компонентами Системы-112;
- красный шарик с крестиком — проблемы со связью с одним или более компонентами.

Щелчок по индикатору открывает всплывающее окно с подробными сведениями о состоянии компонентов. Принимать и обрабатывать карточки происшествий можно при любом состоянии АРМ (iskratechno-2024, стр. 12–13, 16–17).

## 3. Панель функциональных кнопок

Состав (iskratechno-2024, стр. 17):

- **Кнопка вспомогательного меню** — боковое меню: ссылка на руководство по работе с приложением, переключатель тёмной темы интерфейса, сведения о производителе.
- **КАРТА** — открытие окна карты (место происшествия, расположение экстренных служб и пр.).
- **БАЗА ЗНАНИЙ** — открытие руководства пользователя.
- **СВОДКА** — открытие окна сводки (краткий отчет о дежурстве).
- **Кнопки быстрого доступа** — вызов функций или ДДС, относящихся к МО оператора; настраиваются администратором; при наведении — подсказка с комбинацией горячих клавиш.

## 4. Список карточек происшествий

### 4.1 Общие правила

- Список содержит перечень карточек происшествий, зарегистрированных в Системе-112; по каждой — состояние, идентификатор, дата и время создания, место происшествия и т.д. (iskratechno-2024, стр. 18).
- Видимость карточек: операторы 112 и ЕДДС видят все карточки по всем службам и МО; диспетчеры ДДС — только карточки, назначенные в их ДДС (iskratechno-2024, стр. 18; iskrauraltel-2016, стр. 34).
- Открытие карточки: двойной щелчок мыши или клавиша ENTER (iskratechno-2024, стр. 18).
- Над списком — панель управления списком карточек; под списком — элементы управления сменой страниц (iskratechno-2024, стр. 18).

### 4.2 Панель управления списком — режим поиска карточек

При отсутствии входящего обращения на панели — кнопка **НОВОЕ ПРОИСШЕСТВИЕ** и фильтры списка (iskratechno-2024, стр. 18–20):

- Набор доступных фильтров зависит от типа ДДС оператора; состав отображаемых фильтров настраивается через выпадающий список **ФИЛЬТРЫ** (можно добавить/скрыть любые, кроме СОСТОЯНИЕ — оно отображается всегда). Команда «Сбросить фильтры в исходное состояние» возвращает состав и значения по умолчанию.

| Фильтр | Значения / поведение |
|---|---|
| Содержит текст (Поиск) | Поиск по подстроке в полях: идентификатор; тип происшествия; логин оператора, создавшего карточку; элементы адреса (город, улица); дата/время создания (форматы `dd.MM.yyyy HH:mm:ss` и `dd MMM yyyy`); номер телефона обращения; контактный номер обращения; фамилия заявителя |
| Период | «За последние» (Секунды, Минуты, Часы, Дни, Месяцы, Годы) или «Между» (начальная и конечная даты) |
| Состояние | Набор зависит от конфигурации службы. Общие: Все за 24ч / Активная / Реагирование / Завершена. Если служба может назначать другие службы: + Создана / Назначена / Закрыта. Если служба может быть назначена в карточку: + Новая / Обрабатывается / Отменена |
| МО | Мои районы / Все (при отсутствии переключателя фильтр по районам не применяется) |
| Ложные вызовы | Показать / Скрыть (при «Скрыть» карточки с ложным типом не показываются) |
| Уровни ЧС | Все / ЧС / ЕДДС (при «ЧС» показываются все карточки со всеми уровнями ЧС) |
| Статус просмотра | Все / Изменившиеся / Требуют реакции (при «Изменившиеся» показываются и изменившиеся, и требующие реакции) |

### 4.3 Панель управления списком — режим создания карточки

Активируется кнопкой НОВОЕ ПРОИСШЕСТВИЕ, а также автоматически при приеме обращения (iskratechno-2024, стр. 20–21):

- **ОТМЕНА** — возврат в режим поиска карточек.
- **СОЗДАТЬ КАРТОЧКУ** — создание карточки с выбранным типом происшествия (если выбрано «Все» — карточка создается с типом «Не задано») и переход в нее; текущее обращение сохраняется, привязывается к карточке и переводится в режим просмотра.
- **ЛОЖНЫЙ ВЫЗОВ** — список ложных вызовов (преднамеренных и непреднамеренных); при выборе типа создается карточка с соответствующим типом и осуществляется переход в нее.
- Фильтр: выпадающий список **Тип происшествия**.
- При наличии обращения автоматически применяется **фильтр похожих карточек** с текстом «Отфильтровано по текущему обращению»: в списке — все за 24ч карточки, в списке заявителей которых есть текущий заявитель (по номеру телефона), а также карточки происшествий, географически близких к текущему местоположению заявителя (защита от дублирования).

### 4.4 Колонки списка карточек

(iskratechno-2024, стр. 21–22)

| Колонка | Содержимое |
|---|---|
| Состояние | Текущее состояние карточки либо состояние ДДС по каждой привлечённой службе (цветные индикаторы, см. раздел 5) |
| Идентификатор | Составное обозначение: сокращённые дата + тип происшествия + порядковый номер карточки данного типа за эту дату. Пример: `май26_ДТП_008` — восьмое ДТП, зарегистрированное 26 мая. При смене типа происшествия в карточке номер и тип в идентификаторе меняются |
| Дата создания | Время и дата создания карточки |
| Тип происшествия | Тип происшествия (наличие колонки настраивается администратором) |
| Место происшествия | Информация о месте происшествия + значки количества привязанных обращений каждого типа: телефонный вызов, SMS, ЭРА-ГЛОНАСС, ручное обращение; вместо нуля — знак «-» (например, `1 - - 1`) |
| Оператор | Логин последнего оператора, изменившего карточку |

Строка, не помещающаяся в колонку, обрезается тремя точками; полный текст — во всплывающей подсказке (iskratechno-2024, стр. 22).

В iskrauraltel-2016 (стр. 35–36) есть также колонка **№** (порядковый номер в списке, зависит от сортировки/фильтрации; точной ссылкой является идентификатор), а колонка оператора — «логин оператора, создавшего карточку». Пример идентификатора там: `май26_ДТП_08`.

### 4.5 Сортировка и выделение

- Сортировка по возрастанию/убыванию по одной из колонок: **Идентификатор, Создана, Оператор**; щелчок по названию столбца; индикаторы: стрелка вверх (А→Я), стрелка вниз (Я→А) (iskratechno-2024, стр. 22–23). В iskrauraltel-2016 (стр. 36): сортировка по любому столбцу, третий щелчок отключает сортировку.
- Выделение карточки в списке: на карте появляется маркер происшествия и карта центрируется на нем (если карта открыта и у карточки есть координаты); если координат нет — маркер предыдущего выделенного происшествия скрывается (iskratechno-2024, стр. 22).

## 5. Состояния и цветовые индикаторы

### 5.1 Состояния карточки происшествия

Полный перечень состояний карточки/ДДС из фильтра «Состояние» и панели состояния (iskratechno-2024, стр. 20, 31–34):

- **Создана** — карточка создана и сохранена, ДДС ещё не назначены (также — все назначенные ДДС отменены);
- **Назначена** — карточке назначены ДДС, но как минимум одна ДДС не приступила к реагированию;
- **Новая** — ДДС назначена в карточку, но ни один диспетчер этой ДДС не начал её обрабатывать;
- **Обрабатывается (Просмотрена)** — карточка открыта диспетчером ДДС, но ни одна бригада ещё не добавлена;
- **Реагирование** — информация о бригадах добавлена, карточка не завершена;
- **Завершена** — диспетчер ДДС завершил обработку кнопкой ЗАВЕРШИТЬ КАРТОЧКУ (повторное назначение возвращает карточку в Новая/Просмотрена/Реагирование);
- **Отменена** — оператор 112 отменил назначение ДДС; диспетчер ДДС должен зайти и завершить (повторное назначение возможно);
- **Назначается** — внешняя ДДС назначена, подтверждение ещё не пришло (только внешние ДДС);
- **Не назначена** — ошибка при назначении или истекло время подтверждения;
- **Отменяется** — отмена внешней ДДС в процессе (только внешние ДДС);
- **Не отменена** — ошибка отмены внешней ДДС или истекло время подтверждения (только внешние ДДС);
- **Закрыта** — оператор 112 закрыл карточку;
- **Передача данных** — дополнительная индикация к любому из состояний без потери цвета и надписи состояния.

Закрыть карточку можно только из состояний Создана, Завершена или Отменена (iskratechno-2024, стр. 80; iskrauraltel-2016, стр. 27). Кнопка ЗАКРЫТЬ КАРТОЧКУ доступна, если назначенных ДДС нет вообще (карточка в состоянии Создана или Обрабатывается), либо каждая назначенная ДДС Завершена/Отменена/настроена с опцией «Не ждать завершения» (iskratechno-2024, стр. 29–30).

Статусы карточки в конкретной ДДС (контроль реагирования на панели «План реагирования», iskratechno-2024, стр. 38): **Новая** → **Передана** (для внешних ДДС) → **Обрабатывается** → **Реагирование** → **Завершена**; **Отменена** — оператор 112 исключил ДДС или карточке присвоен статус «Ложный вызов».

### 5.2 Индикатор состояния ДДС (внешний вид)

(iskratechno-2024, стр. 33–35)

- Цветной квадрат с текстом — сокращённое название типа службы (для особых ЕДДС — сокращённое название конкретной ОЕДДС); настраивается администратором. Цвет определяется состоянием ДДС.
- Режимы отображения: без анимации (всё подтверждено, данные переданы, квоты не превышены); мигает (проблема: не удалось отправить данные во внешнюю ДДС и/или превышены квоты обработки — подробности в подсказке); с полоской снизу (идёт передача данных во внешнюю ДДС); мигает с полоской (комбинация).
- В списке карточек отображается максимум 11 индикаторов; 12-й заменяется индикатором с количеством скрытых (список — в подсказке по наведению).
- Состояния Закрыта и Завершена всегда отображаются без индикаторов ДДС; если ни одна ДДС не назначена — тоже без индикаторов.
- Отображение индикаторов всех назначенных ДДС в списке и/или в карточке включается настройками конфигурации ДДС.

### 5.3 Индикатор готовности ДДС (цветной круг)

Отображается на вкладке КОНТАКТЫ и на панели «План реагирования» (iskratechno-2024, стр. 37–38, 59–60):

| Цвет | Значение | Подсказка |
|---|---|---|
| Зелёный | Есть хотя бы один свободный оператор | «Есть свободные операторы» |
| Жёлтый | Все зарегистрированные операторы заняты | «Все операторы заняты» |
| Красный | Нет ни одного зарегистрированного оператора (все АРМ выключены/неработоспособны) | «Нет работающих операторов» |
| Серый | Внешняя ДДС, статус неизвестен | «Нет информации об операторах» |
| Серый мигающий | Ошибка передачи данных во внешнюю ДДС (только в карточке с ошибкой) | «Нет информации об операторах» |

В iskrauraltel-2016 (стр. 46) красный мигающий индикатор на панели ДДС означает «карточка назначена, но данные не получены соответствующей ДДС» (для ДДС с собственной ИС, например скорой помощи).

### 5.4 Состояния бригады (этапы реагирования)

Для всех ДДС, кроме 01 (iskratechno-2024, стр. 43, 78):

**Уведомление → Выезд → Прибытие → Ликвидировано / Отменено**

При добавлении этапа в список включаются только состояния ниже текущего; по умолчанию выбрано следующее допустимое (пример: при текущем «Прибытие» доступны «Ликвидировано» и «Отменено», по умолчанию — «Ликвидировано»).

### 5.5 Статусы исходящего SMS

(iskratechno-2024, стр. 57, 72): **в процессе / доставлено / ошибка доставки**. В iskrauraltel-2016 (стр. 20): два значка — «отправлено и получено адресатом» и «не удалось отправить».

### 5.6 Метки карточек в списке

- **ЧС**: красная метка «ЧС» в строке карточки, сама строка выделяется красным цветом (iskratechno-2024, стр. 77). В iskrauraltel-2016 (стр. 26, 35): карточки ЧС выделяются восклицательным знаком.
- **Ложный вызов**: если тип происшествия — один из ложных, в панели состояния карточки отображается текст «Ложный вызов» (iskratechno-2024, стр. 32). В iskrauraltel-2016 (стр. 35): карточки ложных вызовов выделяются серым цветом.
- **ЭРА-ГЛОНАСС**: карточка с состоянием Новая, типом ДТП и пометкой «ЭРАГЛОНАСС» (в iskrauraltel-2016 — в столбце Оператор); появление сопровождается звуковым сигналом (iskratechno-2024, стр. 73; iskrauraltel-2016, стр. 18).
- **Пропущенный вызов**: метка на вкладке СПИСОК ОБРАЩЕНИЙ (iskratechno-2024, стр. 16).
- **«Карточка закрыта»**: текст рядом с состоянием, если данная ДДС назначена и отменена, а карточка закрыта (iskratechno-2024, стр. 32).

### 5.7 Состояния обращения

Типы обращений (iskratechno-2024, стр. 24): **телефонный вызов / SMS / ручное обращение / ЭРА-ГЛОНАСС** — каждому соответствует свой значок на панели работы с обращением. Если обращение не привязано к карточке — красный индикатор; если привязано — ссылка с идентификатором карточки.

Типы записей во вкладке СПИСОК ОБРАЩЕНИЙ (iskratechno-2024, стр. 62): входящий вызов, исходящий вызов, SMS и т.п.; для пропущенного вызова дополнительно — обработан он или нет.

Состояния рабочего места при обращении (iskratechno-2024, стр. 23): при создании обращения вручную АРМ переходит в состояние **ЗАНЯТ** (если приём включён) или **ЗАНЯТ | ВЫКЛЮЧЕН** (если выключен).

## 6. Панель работы с обращением — 3 режима

(iskratechno-2024, стр. 23–25)

1. **«Нет текущего обращения и входящего вызова или SMS»** — текст «Нет обращения» и кнопка СОЗДАТЬ ОБРАЩЕНИЕ (создание обращения вручную, перевод панели в режим редактирования).
2. **«Есть входящий вызов или SMS»** — текст по сценарию: «Есть входящий вызов»; «Есть входящее SMS»; «Вызов устанавливается»; «Выполняется доставка SMS»; «Установлен вызов с <название ДДС оператора>: <логин оператора> (<внутренний номер>)» (входящий вызов от оператора).
3. **«Есть текущее обращение»** — тип обращения (значок + индикатор непривязанности/ссылка на карточку), информация о заявителе (ФИО и дата рождения; телефон и количество ложных вызовов с него — при их наличии строка выделяется красным; контактный телефон; адрес; координаты; адрес проживания; доп. инфо) и кнопки **ИЗМЕНИТЬ** (режим редактирования) и **ЗАВЕРШИТЬ ОБРАБОТКУ** (завершаются все вызовы, выход из всех конференций без их завершения, включается прием обращений, если не был выключен вручную).

В iskrauraltel-2016 (стр. 37–38) на панели обращения есть также кнопка **В черный список** (добавление номера в чёрный список; удалить номер может только администратор) и кнопка «Закончить обработку».

## 7. Панель вкладок

Расположена в правой части экрана; вкладки переключаются вручную и автоматически по содержимому левой части. Верхний уровень — вкладки работы с обращением, нижний — с карточками. Доступная для текущего контекста вкладка выделяется серым (iskratechno-2024, стр. 47–48).

| Вкладка | Назначение | Доступность |
|---|---|---|
| ТЕКУЩЕЕ ОБРАЩЕНИЕ | Контекстная информация по текущему обращению | Только при открытом обращении; автоактивация при приеме вызова/SMS |
| КОНТАКТЫ | Телефонная книга | На любой странице |
| ВЫЗОВЫ | Совершение вызовов и управление ими | На любой странице |
| СПИСОК ОБРАЩЕНИЙ | История обращений | На любой странице |
| ИСТОРИЯ УКИО | История изменений карточки | Только в карточке |
| SMS | SMS-диалог и отправка SMS | На любой странице |

### 7.1 ТЕКУЩЕЕ ОБРАЩЕНИЕ (iskratechno-2024, стр. 49–52)

Две панели: управление обращением и «Информация об обращении».

Панель управления обращением:

- входящий вызов: дата и время поступления, номер телефона заявителя, длительность разговорной фазы;
- установленный вызов: + кнопки удержания и завершения;
- завершенный вызов: + кнопка отправки SMS (активирует вкладку SMS) и кнопка вызова заявителю (исходящий вызов, вкладка ВЫЗОВЫ);
- SMS: дата и время поступления, номер, кнопки SMS и вызова, текст SMS;
- ручное обращение: только время создания;
- общее: если номер в чёрном списке — количество ложных вызовов.

Панель «Информация об обращении» (не отображается для ручного обращения): информационные блоки-события, отсортированные по времени (новые сверху). Структура блока: значок типа, время, данные в нескольких строках, тип блока (например, «Оператор связи - МО вызова»), кнопки **ЗАЯВИТЕЛЬ** (перезапись полей ФИО в УЧОЛ данными блока, целиком, включая пустые), **МЕСТОПОЛОЖЕНИЕ ЗАЯВИТЕЛЯ** (перезапись адреса и координат УЧОЛ; если адрес есть, а координат нет — геокодинг; адрес регистрации не переносится), **ЗАПРОС МЕСТОПОЛОЖЕНИЯ** (повторное определение местоположения; только для обращений, привязанных к незакрытой карточке).

### 7.2 ВЫЗОВЫ (iskratechno-2024, стр. 53–56)

- **Номеронабиратель**: поле ввода номера + кнопка вызова; при вводе ≥3 символов — поиск номера по справочнику контактов, под полем отображается имя.
- **Вызовы**: все текущие вызовы и конференции оператора (активные или на удержании). Входящий вызов — только один; активных исходящих — несколько (вызываемые не слышат друг друга). При исходящем вызове входящий автоматически ставится на удержание. Переадресованный (соединённый со входящим) вызов может быть только один, его можно только завершить.
- Действия с вызовами: завершить; поставить/снять с удержания; соединить исходящий со входящим; добавить в конференцию (в существующую или новую).
- Действия с конференциями: завершить; поставить на удержание (временно покинуть — можно принимать новые вызовы). Действия с участниками: исключить с завершением вызова; исключить без завершения; поставить на удержание без исключения.
- Кнопки: НОВАЯ (новая конференция со всеми вызовами), ОТМЕНА, ДОБАВИТЬ; значки: добавить в конференцию/создать новую; удержание/выйти из конференции; отклонить/завершить; исключить участника без завершения вызова; удалить конференцию и завершить все вызовы; перевод входящего вызова на этот вызов.
- При активной конференции исходящий вызов автоматически добавляется в конференцию.

### 7.3 SMS (iskratechno-2024, стр. 56–57)

Текущий номер и имя из обращения; вся переписка с абонентом (новые внизу); у исходящих — индикатор статуса (в процессе/доставлено/ошибка доставки); выпадающий список **Шаблоны SMS** (настраивается администратором); поле «Введите сообщение»; кнопка «Отправить сообщение».

### 7.4 КОНТАКТЫ (iskratechno-2024, стр. 57–59)

- Два справочника без видимого разделения: **ДДС** (все ДДС, кроме ДДС активного оператора; у каждой — индикатор готовности, название, тип, адрес, номер телефона очереди, список резервных номеров с кнопкой вызова) и **Справочник** (контакты по секциям, настраивается администратором; у каждого контакта название и упорядоченный список телефонов с кнопкой ВЫЗОВ).
- Поиск «Найти контакт» — по подстроке в названии контактов (фактически фильтр).
- Группировка (только для ДДС): Не задана / Службы / МО; при группировке по службам — фильтр «Тип службы», по МО — фильтр «МО».
- Фильтр «Состояние»: Все / Онлайн (только ДДС с зелёным или серым индикатором готовности).

### 7.5 СПИСОК ОБРАЩЕНИЙ (iskratechno-2024, стр. 61–63)

- Поиск «Найти обращение» — по полям Фамилия и Номер телефона заявителя.
- Фильтр: Все / Пропущенные (только пропущенные необработанные) / Карточка (только вызовы, привязанные к текущей карточке; активируется автоматически при переходе на вкладку с открытой карточкой).
- Сортировка: Сначала старые / Сначала новые; фильтр ПЕРИОД.
- Данные по каждому вызову: тип (для пропущенного — обработан/нет), дата и время регистрации, идентификатор привязанной карточки, оператор и его ДДС, ФИО и день рождения заявителя, телефон (всегда), контактный телефон, адрес (всегда), дополнительная информация.
- Действия: позвонить; отправить SMS; прослушать вызов (встроенный плеер); скачать файл вызова; детали обращения (история местоположений) — режим отображения деталей с блоком «Информация об обращении».

В iskrauraltel-2016 (стр. 39) «История обращений» — отдельное окно: дата/время, ФИО/телефон, данные поля «Уточнение», прослушивание, сохранение в файл, показ на карте, обратный вызов/SMS.

### 7.6 ИСТОРИЯ УКИО (iskratechno-2024, стр. 63–65)

- История изменений карточки, 20 записей на страницу; переход на соседние и на первую/последнюю страницы.
- Индикатор непросмотренных изменений — оранжевый шарик на заголовке вкладки (исчезает после просмотра).
- Фильтр «Категория»: Все / Основная информация / Место происшествия / Специфичные данные ДДС / Назначенные ДДС.
- Сортировка: Сначала старые / Сначала новые; фильтр ПЕРИОД.

## 8. Окно входящего вызова или SMS

Содержимое (iskratechno-2024, стр. 65):

- ФИО;
- дата рождения в формате `гггг-мм-дд`;
- номер телефона: `Номер: <номер>`; если номер в чёрном списке: `Номер: <номер> (предн. ложные вызовы: <количество>)`, вся строка выделена красным;
- местоположение; если источник — предыдущее обращение, добавляется текст «(местоположение из предыдущего обращения)»;
- для SMS: `Сообщение: <текст SMS>`.

Отсутствующие строки не отображаются, но строки местоположения и телефона показываются всегда. Окно автоматически обновляется при поступлении новой информации. Кнопки ПРИНЯТЬ/ОТКЛОНИТЬ (iskratechno-2024, стр. 71–72); в iskrauraltel-2016 (стр. 16) окно называется «Входящий вызов», для SMS-обращения уведомление содержит номер, координаты местоположения и текст SMS (стр. 19).

## 9. Карта местности

(iskratechno-2024, стр. 66–67)

- Открывается в новом окне кнопкой КАРТА (можно перетащить на дополнительный монитор); при открытии центрируется на координатах ДДС оператора; внешний вид зависит от провайдера ГИС.
- Возможности: отображение текущих координат под курсором; отображение ДДС собственными значками; текущее местоположение заявителя (синий цвет: маркер при точных координатах, круг или «дуга» — сектор с внутренним/внешним радиусом — при приблизительных); выбранное происшествие (красный цвет); камеры (щелчок — окно просмотра видео); поиск адреса с автозаполнением; слои ГИС; транспортные средства в реальном времени.
- В iskrauraltel-2016 (стр. 50–52): карта открывается автоматически после запуска АРМ (отключается в «Настройки → Открывать карту при входе»); значки: заявитель, место происшествия, ЦОВ, ДДС пожарной охраны/полиции/скорой/газовой службы/ЖКХ/«Антитеррор», ЕДДС; место происшествия отображается при выборе карточки в списке при наличии координат.

### 9.1 Транспортные средства (ТС) на карте

(iskratechno-2024, стр. 67)

- Цвета маркеров: **жёлтый** — активно (реагирование по другой карточке); **красный** — занято (реагирование по выбранной карточке); **зелёный** — свободно, доступно для назначения. Неактуальные данные — диагональная штриховка. На маркере — тип службы объекта.
- В карточке: все ТС, назначенные на происшествие (красные) + остальные (жёлтые, зелёные); в закрытой карточке — только жёлтые и зелёные. В списке карточек: жёлтые и зелёные; при выделении карточки — красные ТС, назначенные на неё.
- Фильтр видимости: флажок «Отобразить все ТС» + отдельные флажки по цветам (свободные/активные/занятые по карточке).
- Щелчок по маркеру — подсказка: регистрационный номер, информация, название бригады.

## 10. Сводка за день

(iskratechno-2024, стр. 68)

- Открывается кнопкой СВОДКА; назначение — краткий отчет о дежурстве, просмотр отчетов других операторов, быстрое оповещение участников системы (сбои, переключение на другой сервер, нештатные ситуации).
- Заполнение — встроенный мини-редактор; после кнопки «Отправить» текст попадает в список отчетов без возможности редактирования и удаления; снабжается меткой времени и автором (логин).
- В списке — отчеты за два дня, новые внизу.
- Уведомление о новом сообщении — красный шарик в правом верхнем углу кнопки СВОДКА; при входе в систему или открытии сводки все сообщения считаются прочитанными.

## 12. Дополнения из iskrauraltel-2016 (= arm-edds)

Элементы интерфейса, присутствующие только в версии 2016 г.:

- Кнопка **Автоназначение служб** — одновременное назначение (или отмена) нескольких ДДС по типу происшествия и району (стр. 23, 40).
- Кнопка **Ложный/Обычный вызов** — присвоение/отмена статуса «Ложный вызов»; после присвоения все назначенные ДДС автоматически отменяются, появляется кнопка «Закрыть карточку» (стр. 25, 40).
- Кнопка **+Данные** на панели ДДС — внесение специфичных для ДДС данных (стр. 46).
- Вкладка **Дополнительные данные** в карточке — данные из внешних систем (например, «Безопасный город») (стр. 47).
- При повторном обращении: автоматическое отображение связанных происшествий и надпись «Найдены происшествия данного заявителя» (стр. 17).
- Область «Общие сведения»: счётчики «Обращений в очереди» (Вызовы, SMS) и «Карточек в состоянии Новая» (для АРМ ДДС — карточки без начатого реагирования; для операторов 112 — новые карточки ЭРА-ГЛОНАСС) (стр. 33).
- Панель управления вызовами «Телефон»: вкладки Звонки / Контакты / Набор / SMS (стр. 49–50).
- Тип происшествия «Злонамеренный вызов» выбирается в списке типов карточки с назначением ДДС полиции и ЕДДС (стр. 25).

## 13. Другой вендор: СПО-112 (protei-2024)

Структура интерфейса веб-приложения «Дежурно-диспетчерский центр» (protei-2024, стр. 15–19):

1. **Панель управления** (вверху): кнопка состояния (статуса работы) оператора с выбором вида деятельности (после авторизации устанавливается «В работе»); кнопки переключения рабочих столов; кнопка микрофона; меню пользователя (редактор рабочих столов, горячие клавиши, информация о РМО, выход, отключение доп. звука).
2. **Виджет «Управление активностями»** (слева вверху): строка статуса активности (Готов/Заблокирован), поле ввода номера, кнопки управления вызовами, кнопки управления чатом (активны при SMS).
3. **Область работы с данными** (центр): разделы «Происшествия» и «Отчеты»; интерактивная карта в отдельном блоке. Режимы работы: «Оперативный режим» (приём вызовов, регистрация) и «Режим статистики» (уведомления о карточках отключены; кнопка «Скачать журнал» — выгрузка списка УКИО в xls/xlsx) (стр. 19, 25–26).
4. Настройка рабочих столов: редактор-конструктор виджетов, до 4 рабочих столов, drag&drop виджетов (стр. 19–22); переназначение горячих клавиш (стр. 23–24).

Список обращений (protei-2024, стр. 27–33):

- Вкладки: **Все происшествия** и **Нарушен регламент** (карточки, созданные с нарушением порядка заполнения полей). По умолчанию — обращения за прошедшие сутки.
- Колонки по умолчанию: Дата (дата и время создания); Создатель, ФИО оператора; УКИО (номер); Состояние (Запрос 112, Подключение, Реагирование, В работе, Отработана, Просмотр); Тип вызова; Номер звонящего; Набранный номер; Место происшествия; Район; Округ. Столбцы настраиваются (флажки, drag&drop, ширина вручную); «Дата» и «УКИО» не скрываются.
- Фильтры: «Фильтр по происшествиям» (произвольный набор полей: номер УКИО, тип, адрес, комментарий, адрес заявителя) и «Фильтр списка карточек» (фиксированный набор: блок «Тип происшествия» — Служба, Тип вызова, флаги Важная/Учебная/Экстренный тип вызова/Угроза ЧС; блок «Период» — За 24 часа/Период; блок «Состояние карточки» — запрос 112, подключение, реагирование, в работе, отработана, просмотр, отказ (по одному значению); блок «Место происшествия» — Район, Район города, Округ; блок «Источник» — Номер звонящего, Источник, Создатель; блок «Информация о заявителе» — Фамилия, Имя, Отчество, Телефон) (стр. 29–31).
- Область предварительного просмотра УКИО рядом со списком (стр. 33–34).

Карточка происшествия (protei-2024, стр. 35–36, 46): дополнительные вкладки справа — **Карта, История, Чат** (при подключении доп. служб), **Дубли** (при выявлении вероятного дубля), **Звонки и СМС, ГЛОНАСС** (при карточке от ЭРА-ГЛОНАСС); вкладка «УКИО» + вкладки подключенных служб (название = служба, цвет = текущее состояние УКИО).

Карта ГИС (protei-2024, стр. 49–51): маркеры происшествий (двойной щелчок — открытие карточки; максимум 99 маркеров); измерение расстояния; прокладка маршрута; центровка по координатам; режимы маркеров по адресам/координатам; скрытие геометок (не скрывать/все/только отработанных); полноэкранный режим.

Печать УКИО (protei-2024, стр. 51–52): варианты «Карточка 112» и «Сводная карточка» (pdf).

Горячие клавиши РМО (protei-2024, Приложение 1, стр. 128): 11 настраиваемых действий — ответить на входящий вызов; сбросить вызов; вкл/выкл удержание; вкл/выкл микрофон; открыть меню подтверждения услуги; открыть номеронабиратель; следующий/предыдущий рабочий стол; выйти из системы; вкл/выкл режим редактирования; вкл/выкл меню блокировки оператора. (Конкретные сочетания в текстовом дампе отсутствуют — заданы изображениями кнопок.)
