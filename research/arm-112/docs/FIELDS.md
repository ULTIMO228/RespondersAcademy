## 1. Унифицированная часть опросного листа (УЧОЛ / карточка обращения)

Панель УЧОЛ в режиме редактирования содержит информацию о текущем заявителе: ФИО, местоположение, телефон и прочие поля. Открывается автоматически при создании обращения или кнопкой ИЗМЕНИТЬ на панели работы с обращением; одновременно активируется вкладка ТЕКУЩЕЕ ОБРАЩЕНИЕ (iskratechno-2024, стр. 25).

### 1.1 Поля и блоки

| Поле / блок | Тип | Описание | Источник |
|---|---|---|---|
| Повод обращения (доп. информация) | текст | Что произошло, дополнительная важная информация о случившемся; опрос заявителя начинается с этого поля | iskratechno-2024, стр. 26 |
| Широта | число | Текущее местоположение абонента; при ручном изменении (вместе с долготой) маркер перемещается и выполняется обратный геокодинг | iskratechno-2024, стр. 26–27 |
| Долгота | число | См. Широта | iskratechno-2024, стр. 26–27 |
| Точность | число | Радиус круга на карте; при ручном изменении координат безусловно сбрасывается в 0 (ненулевое значение даёт только оператор связи) | iskratechno-2024, стр. 26–27 |
| Уточнение | текст | Ориентиры рядом с местом происшествия (здания, магазины, объекты инфраструктуры) | iskratechno-2024, стр. 28 |
| Адрес (адрес проживания заявителя) | текст/блок | Не обязателен; заполняется оператором в ходе опроса | iskratechno-2024, стр. 28 |
| ФИО заявителя | текст | Отображается на панели обращения вместе с датой рождения; может автозаполняться | iskratechno-2024, стр. 24–25 |
| Дата рождения | дата | Формат `гггг-мм-дд` (в окне входящего вызова) | iskratechno-2024, стр. 24, 65 |
| Телефон заявителя | телефон | Вместе с количеством ложных вызовов с него; при наличии ложных вся строка выделяется красным | iskratechno-2024, стр. 24 |
| Контактный телефон | телефон | При наличии | iskratechno-2024, стр. 24 |
| Адрес | блок | Блок полей адреса; меняется только целиком (см. 1.3) | iskratechno-2024, стр. 24–25 |
| Координаты | блок | См. выше | iskratechno-2024, стр. 25 |
| Адрес проживания | текст | При наличии | iskratechno-2024, стр. 25 |
| Доп. инфо | текст | — | iskratechno-2024, стр. 25 |

Кнопки УЧОЛ (iskratechno-2024, стр. 27–28): **Адрес из координат** (карта переходит в режим обратного геокодинга: щелчок задаёт координаты и может изменить адрес), **Указать на карте** (карта переходит в режим задания координат, адрес не меняется), **СОХРАНИТЬ** (сохранение обращения, отправка на сервер).

### 1.2 Автозаполнение и одновременное редактирование

- Часть полей (адрес, ФИО, телефон) может быть заполнена при первом открытии и дозаполняться/изменяться автоматически после открытия (iskratechno-2024, стр. 25).
- Правило: поле, заполненное оператором, НЕ обновляется новой информацией (включая координаты, заданные вручную или точкой на карте) (iskratechno-2024, стр. 25).
- Адрес меняется только целиком: если оператор изменил хотя бы одно поле адреса, никакие поля адреса больше не обновляются автоматически; новые данные показываются значками конфликта (iskratechno-2024, стр. 25).
- Одно обращение могут одновременно редактировать несколько операторов (iskratechno-2024, стр. 26).
- При изменении полей УЧОЛ по внешним причинам — всплывающие сообщения (iskratechno-2024, стр. 26).
- Если источник местоположения — предыдущее обращение: метка **«Местоположение из предыдущего обращения»** (сигнал проверить адрес) (iskratechno-2024, стр. 26).
- Возможен текст «Координаты могут не соответствовать адресу» (iskratechno-2024, стр. 27).

### 1.3 Подтверждение адреса в ФИАС

- Зелёная галочка — адрес подтверждён базой ФИАС; обязательно для карточек, направляемых в ДДС с собственными информационными системами (в частности, ДДС скорой медицинской помощи) (iskratechno-2024, стр. 26; iskrauraltel-2016, стр. 41).
- Восклицательный знак — несовпадение введённого адреса с данными ФИАС (iskratechno-2024, стр. 26).
- В iskrauraltel-2016 (стр. 41) индикатор подтверждает указанный город (населённый пункт). В брошюре Искры 2025 г. (broshyura-s112, стр. 7) упоминается заполнение адресных полей по справочнику **ГАР (ранее — ФИАС)**.

## 2. Карточка происшествия (УКИО)

Карточка открывается при создании или открытии существующей; состоит из панелей (блоков). В режиме редактирования может находиться только один блок; кнопка СОХРАНИТЬ активна только после внесения изменений; при сохранении изменения отправляются на сервер и видны сразу (iskratechno-2024, стр. 29, 46).

### 2.1 Панель состояния карточки

(iskratechno-2024, стр. 31–32)

- **Создана** — дата и время создания, логин оператора, название его ДДС;
- **Изменена** — дата и время последнего изменения, логин оператора, название его ДДС;
- **Закрыта** — вместо даты изменения — дата и время закрытия с соответствующим текстом;
- **Идентификатор карточки**; при ложном типе происшествия — текст «Ложный вызов»;
- **Состояние карточки** (или состояние данной ДДС, если она назначена); текст «Карточка закрыта» — если данная ДДС назначена и отменена, а карточка закрыта;
- **Индикаторы состояния ДДС** для каждой назначенной службы.

Кнопки панели управления карточкой (iskratechno-2024, стр. 29–31): ПОДПИСАТЬСЯ НА ИЗМЕНЕНИЯ КАРТОЧКИ (только операторы 112/(О)ЕДДС при включённом функционале), ЗАКРЫТЬ КАРТОЧКУ, ЗАВЕРШИТЬ КАРТОЧКУ (для назначенной ДДС, с диалогом подтверждения), ПЕЧАТЬ (экспорт в PDF, варианты «Полный»/«Сокращенный»), ПРИВЯЗАТЬ ОБРАЩЕНИЕ (если есть непривязанное обращение; далее — «ОБРАЩЕНИЕ ПРИВЯЗАНО»), кнопки навигации МЕСТО/ДДС/ДАННЫЕ, В СПИСОК КАРТОЧЕК (при несохранённых изменениях — диалог подтверждения).

### 2.2 Панель «Общие сведения»

Режим просмотра и редактирования (iskratechno-2024, стр. 35–36):

| Поле | Тип | Значения / примечание |
|---|---|---|
| Тип происшествия | выпадающий список | При изменении типа меняется идентификатор карточки (iskrauraltel-2016, стр. 40) |
| Время происшествия | дата/время | При создании заполняется текущим; оператор может изменить |
| МО (район) происшествия | выпадающий список | От выбора зависит отображение карточки у операторов района (iskrauraltel-2016, стр. 40) |
| Признак Блокирование | флажок | — |
| Признак Угроза людям | флажок | Опасность увеличения числа пострадавших/погибших (iskrauraltel-2016, стр. 40) |
| Уровень (серьезности) | выпадающий список | Все настроенные уровни происшествия, отсортированные по алфавиту (например: **Обычное, ЧС** и т.п.) |
| Число пострадавших | число | Изменение может автоматически изменить Уровень (метка «Внимание: уровень был установлен автоматически») |
| Число погибших | число | См. выше |
| Дополнительная информация | текст | Редактируемо даже в режиме просмотра панели |

Значения справочника «Уровень» из iskrauraltel-2016 (стр. 40):

- **Обычное** — пострадавших до 10 и погибших до 3 человек;
- **ЧС** — пострадавших свыше 10 и погибших свыше 3 человек;
- **ЧС в субъекте** — ЧС регионального характера, пострадавших от 50 до 500 человек.

Регистрация ЧС: выбор уровня ЧС вручную или ввод чисел пострадавших/погибших (уровень выбирается автоматически) (iskratechno-2024, стр. 77).

### 2.3 Панель «Место происшествия»

(iskratechno-2024, стр. 36–37; iskrauraltel-2016, стр. 41–42)

В режиме просмотра отображаются заполненные группы: **Адрес** (если заполнено хотя бы одно поле блока «Адрес в населенном пункте», включая поле «Уточнение места происшествия» — «Уточн. …»), **Адресный участок** (если заполнен участок или его улица), **Дорога** (если заполнено название дороги, километровая или метровая отметки), **Координаты** (если заполнено хотя бы одно поле координат).

Типы адреса (переключатель в режиме редактирования):

- **Адрес в населенном пункте** — известен точный адрес (состав полей — как в УЧОЛ, в дампе поимённо не перечислен);
- **Вне населенного пункта** — происшествие относится сразу к нескольким адресам или точный адрес указать невозможно;
- **Дорога** — происшествие на дороге/рядом с ней, вдали от населённых пунктов.

Дополнительно: **Координаты**, кнопка **Указать на карте** (ввод координат и адреса точкой на карте — iskrauraltel-2016, стр. 41–42), поле **Уточнение** (текстовый комментарий о месте).

### 2.4 Панель «План реагирования» (назначение ДДС)

(iskratechno-2024, стр. 37–39)

- **Индикатор текущего состояния ДДС** (зелёный/красный/серый/серый мигающий/жёлтый — см. INTERFACE.md, раздел 5.3).
- **Раскрывающиеся списки ДДС** — адреса и наименования конкретных отделений/частей ДДС; по умолчанию выбираются ДДС того МО, к которому принадлежит оператор.
- Кнопки: **Назначить** (привлечение ДДС; карточка появляется в списке АРМ этой ДДС), **Отменить** (карточка остаётся у ДДС с состоянием Отменена), **Вызов** (вызов оператора ДДС), **Назначить все** (назначение всех добавленных, но не назначенных ДДС).
- В строке каждой назначенной ДДС — кнопка-шеврон: раскрытие этапов реагирования (для каждой бригады — название, состав, все действия, их время и примечания; обновляется автоматически).
- Статусы карточки в ДДС: Новая / Передана (внешние ДДС) / Обрабатывается / Реагирование / Завершена / Отменена (подробности — INTERFACE.md, раздел 5.1).

### 2.5 Панель «Данные ДДС» (специфические части)

(iskratechno-2024, стр. 39–42)

- У операторов 112 и ЕДДС — кнопки/индикаторы для всех возможных типов ДДС: галочка (специфическая часть этого типа уже добавлена), «крестик» (добавить специфическую часть соответствующего типа — открывается в режиме создания). У диспетчеров ДДС — только специфическая часть своего типа.
- Режимы: просмотр (кнопки/индикаторы всех ДДС + все заполненные поля добавленных ДДС), создание (кнопка СОХРАНИТЬ доступна сразу), редактирование (все поля специфической части + СОХРАНИТЬ/ОТМЕНИТЬ; СОХРАНИТЬ неактивна до изменений; редактирование остальных частей карточки блокируется).
- Элементы списков (например, пациентов) отображаются в режиме просмотра; добавление/изменение — через диалог; кнопка СОХРАНИТЬ диалога сразу отправляет данные на сервер (ОТМЕНИТЬ операции со списками не отменяет).
- **Состав полей специфических частей в текстовом дампе не приведён** (только рисунки панелей для ДДС 01 и др.).

### 2.6 Панель «Назначение сил и средств»

Отображается только если у ДДС есть собственные силы и средства (iskratechno-2024, стр. 42–45).

Режим «Назначение бригады» (кнопка ДОБАВИТЬ БРИГАДУ; если свободных нет — текст «НЕТ СВОБОДНЫХ БРИГАД»):

| Поле | Тип | Значения / примечание |
|---|---|---|
| Бригада | выпадающий список | Названия всех бригад, не назначенных в текущую карточку |
| Состав | текст/список | По умолчанию — настроенное значение; оператор может изменить (личный состав бригады) |
| Состояние | выпадающий список | Для всех ДДС, кроме 01: **Уведомление / Выезд / Прибытие / Ликвидировано / Отменено**; при добавлении этапа — только состояния ниже текущего, по умолчанию следующее допустимое |
| Время | дата/время | По умолчанию текущее; можно изменить (время начала этапа) |
| Примечание | текст | По умолчанию пусто |
| ДОБАВИТЬ | кнопка | Добавление бригады в список назначенных |

Таблица назначенных бригад (сортировка — в порядке добавления): колонки **№** (номер по порядку), **Время** (время последнего действия), **Бригада** (название), **Состояние** (последнее действие), **Состав**, **Примечание** (две строки, далее обрезается; полный текст по наведению). Кнопки строки: добавление этапа реагирования; генерация **путевого листа** (данные о происшествии и бригадах + карта с маркером места происшествия; печать); сворачивание/разворачивание информации о силах и средствах ДДС.

### 2.7 Панель «Результат реагирования»

Отображается только у служб, имеющих бригады; оператор может задать или изменить результат реагирования (режим просмотра/редактирования с кнопками ИЗМЕНИТЬ/СОХРАНИТЬ) (iskratechno-2024, стр. 46, 79). **Состав полей в текстовом дампе не приведён** (только рисунки).

### 2.8 Общие механизмы блоков карточки

(iskratechno-2024, стр. 46–47)

- Кнопка фильтра истории изменений в большинстве блоков — активирует вкладку ИСТОРИЯ УКИО с фильтром по текущему блоку; вариант кнопки с индикатором — есть непросмотренные изменения.
- Кнопка редактирования блока — перевод в режим редактирования (одновременно только один блок).
- Всплывающие информационные окна (например, «Карточка изменена оператором ХХХ», «Сообщение доставлено»).
- Оранжевый шарик на вкладке ИСТОРИЯ УКИО — непросмотренные изменения (исчезает после просмотра).

## 3. Данные заявителя и список заявителей

### 3.1 Окно входящего вызова/SMS — данные заявителя

(iskratechno-2024, стр. 65): ФИО; дата рождения (`гггг-мм-дд`); номер телефона (для чёрного списка — с количеством преднамеренных ложных вызовов, строка красным); местоположение (с пометкой «(местоположение из предыдущего обращения)», если источник — предыдущее обращение); для SMS — текст сообщения. Строки телефона и местоположения показываются всегда.

### 3.2 Блоки «Информация об обращении»

(iskratechno-2024, стр. 52): события системы (например, тип «Оператор связи - МО вызова»), кнопки ЗАЯВИТЕЛЬ / МЕСТОПОЛОЖЕНИЕ ЗАЯВИТЕЛЯ / ЗАПРОС МЕСТОПОЛОЖЕНИЯ. Упоминается **адрес регистрации** — неформатированный адрес вида `Калининград~г~Александровская~п~Дружбы~ул; 26;Дом`; в УЧОЛ не переносится.

### 3.3 Список заявителей карточки

(iskrauraltel-2016, стр. 23, 45; iskratechno-2024, стр. 77)

- Содержит все обращения, привязанные к карточке; функционально аналогичен истории обращений (прослушивание записи, обратный вызов).
- Пополнение: автоматически при создании карточки в момент активного обращения; вручную кнопкой ПРИВЯЗАТЬ ОБРАЩЕНИЕ. Карточки ЭРА-ГЛОНАСС создаются автоматически.
- Данные строки: дата/время поступления вызова; ФИО и телефон заявителя; данные поля «Уточнение» из УЧОЛ; действия (прослушать запись, сохранить в файл, показать на карте, обратный вызов/отправка SMS).
- Обращение не может быть привязано к нескольким карточкам; к одной карточке — несколько обращений (iskratechno-2024, стр. 31).

### 3.4 Поля записи во вкладке СПИСОК ОБРАЩЕНИЙ

(iskratechno-2024, стр. 62): тип (входящий/исходящий вызов, SMS; для пропущенного — обработан/нет); дата и время регистрации; идентификатор привязанной карточки; оператор и его ДДС; ФИО и день рождения заявителя; телефон (всегда); контактный телефон; адрес (всегда); дополнительная информация.

## 4. История изменений карточки

### 4.1 Вкладка ИСТОРИЯ УКИО (iskratechno-2024, стр. 63–65)

- 20 записей на страницу; навигация на соседние/первую/последнюю страницы.
- Фильтр «Категория»: **Все / Основная информация / Место происшествия / Специфичные данные ДДС / Назначенные ДДС** (изменение показывается, если хотя бы одна его категория соответствует фильтру).
- Сортировка «Сначала старые/новые», фильтр ПЕРИОД; индикатор непросмотренных изменений — оранжевый шарик.

### 4.2 Что регистрируется в истории (iskrauraltel-2016, стр. 45–46)

- ввод и удаление данных во всех полях карточки, включая списки и специфические данные ДДС;
- изменения состояния карточки;
- привязка новых обращений;
- отмена назначенной ДДС и причина отмены;
- время и дата всех изменений;
- имя/логин и **IP-адрес** оператора, внёсшего изменения.

Старые (изменённые/удалённые) данные сохраняются в истории — просмотр по наведению на значок.

### 4.3 История карточки в СПО-112 (protei-2024, стр. 56)

Вкладка «История»: учетная запись оператора; дата и время изменений; наименования изменённых полей. Доступен просмотр любой версии карточки (без редактирования), возврат к последней версии, экспорт истории в xls.

## 5. УКИО в СПО-112 (protei-2024) — полная спецификация полей

Форма карточки имеет блочную структуру из четырёх информационных блоков (protei-2024, стр. 35–40). Обязательные поля выделяются красным цветом (стр. 37).

### 5.6 Состояния УКИО и кнопки завершения создания (protei-2024, стр. 28, 31, 36)

- Состояния УКИО: **Запрос 112, Подключение, Реагирование, В работе, Отработана, Просмотр, Отказ**.
- Кнопки нижней панели формы: Сохранить; Завершить работу с карточкой (→ состояние «Отработана»); при создании по вызову — Передать без вызова / Передать с вызовом / Конференция; Справочный / Ложный / Детская шалость (тип вызова, карточка → «Отработана»); Отмена.
- Дубли карточек: вкладка «Дубли» при одновременном выполнении 5 условий (карточка-претендент не старше 24 ч; создана ранее; у неё выставлен тип вызова; совпадает тип происшествия или у текущей не указан; совпадает входящий номер, или контактный номер, или улица+дом, или округ+дом без улицы, или район+дом без улицы и округа) (стр. 53–54). Кнопки: Дубликат / Дубликат с переносом данных / Не дубликат / Отвязать дубликат; карточке-дубликату присваивается тип вызова «Повторный» и статус «Отработана» (стр. 55).

### 5.7 Типы информационных полей приложения (protei-2024, Приложение 2, стр. 129–133)

- **Числовые поля** — номер телефона, индекс, номер паспорта и т.д.
- **Символьные поля** — ФИО, должность, email и т.д.
- **Календарные поля** — даты/интервалы; форматы `dd/mm/yyyy` и `hh:mm:ss`; календарь с выбором дня/месяца/года/времени (ЧЧ:ММ или ЧЧ:ММ:СС).
- **Классификатор** — значение из систематизированного перечня; фильтрация списка по мере ввода символов; введённое вручную значение вне списка → сохранение невозможно (подсветка красным).
